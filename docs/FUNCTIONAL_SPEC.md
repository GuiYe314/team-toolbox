# 设备调试工具功能规格

本文描述目标行为；实际状态以 PROJECT_STATUS 为准。

## F-DEV-001 独立设备调试发行版（TASK-038）

- 将 Unity 日志与安卓调试合成一个独立工具，建立 `codex/device-debugger` 分支；保留主线文件、真实数据与未提交改动。
- 首页只展示两个工具，导航提供安卓调试、Unity 日志与设置；保留明暗主题、帮助和 ADB 配置弹窗。直接刷新工具深链可用，无其他工具界面或接口。
- Express 后端只装配两组设备 API 和健康检查，不打开数据库、不注册其他业务或完整工具箱更新 API；生产依赖限 express/yauzl，测试依赖与生产包隔离。
- 默认端口 3100（源码 Vite 5174），默认启动器 Lan/可选 Local；同网段真实来源、服务器 Host、浏览器同源、专用头、参数/确认/取消边界保持原有规则。
- 机器配置相对独立程序目录的 data/，不自动复制完整工具箱配置或设备内容。停止按程序路径/身份，不干扰原工具箱；启动成功关闭 CMD，失败明确提示。
- 独立 Windows 安装身份、完整便携包、校验与产品清单；内置 Node，独立目录生产启动及 Local/Lan 验收，上传分支并正式发布，不能替换原主线 latest 或 manifest。

## F-ADB-001 安卓调试（沿用）

保留 ADB 搜索/配置、mDNS/IPv4/二维码及六位码配对、设备列表、HOME 应用选择和确认、六项常用与自定义命令、单台/最多20台 APK 一次上传逐台安装、Logcat/包名进程隔离、网页截图与连续刷新。进程参数列表/隐藏/超时/输出限制/取消保留；配对口令只在内存与 stdin，安装保留应用数据，取消不回滚已完成安装。

## F-ULOG-001 Unity 日志（沿用）

只读搜索真实私网网段内专用日志服务，最多1024地址/64并发/25秒，历史文件/预览/全文/ZIP下载和取消。票据只在服务内存，固定协议/路径，不接收自由URL或公网地址。Unity侧必须运行包含发现协议的完整新版 Assets/Test/Log；没有删除/清空设备日志。

## F-ADB-002 Unity persistentDataPath 文件管理（TASK-039）

- 原工具箱与独立设备调试工具共用相同实现。在安卓调试选择明确在线设备及已安装应用，按当前 Android 用户定位标准 `/storage/emulated/<用户>/Android/data/<包名>/files`；不猜测 Unity 类型，不访问私有内部目录或获取 root。自定义路径与厂商权限限制明确说明。
- 支持逐层浏览（包括隐藏文件）、返回上级、UTF-8 文本预览与文件下载；单目录最多1000条，预览256KiB，下载/上传单文件最多256MiB。不存在目录/权限不足/不兼容命令须明确反馈，不能当空目录成功。
- 添加文件只创建新文件；替换需从当前列表选择文件，展示设备/应用/相对路径与大小并二次确认，带读取时版本，提交前复核当前用户与文件版本。先随机临时文件传送、核对SHA256再同目录提交；取消或失败清理临时内容，成功后刷新。不能递归替换目录、删除用户文件、自动停止应用或自动改权限。建议先下载备份并由用户关闭会写入这些文件的App。
- 远端固定脚本配合字面量参数转义，拒绝绝对路径/越级/控制字符/符号链接与特殊文件，进程隐藏/超时/输出限制/取消；上传流式落私有临时目录，不进入团队数据库/备份或操作日志正文。页面离开/后台/切换设备应用/配置变化清理等待与旧结果。
- 默认离线测试覆盖参数、目录协议、权限、读取、二次确认、版本冲突、传送核验和失败取消清理；隔离浏览器覆盖添加/替换/下载及生命周期。真机兼容性另记，不把模拟ADB结果当真机验收。

## F-ADB-003 查看 APK 包名（TASK-040）

- 安卓调试提供独立“查看 APK 包名”面板：选择浏览器可见的单个 APK，主动读取包名并复制；不要求 ADB、SDK、手机或安装操作。支持标准编译后的 UTF-8/UTF-16 二进制 AndroidManifest.xml，资源引用或损坏清单明确报错，不猜测结果。
- APK最多1GiB，上传流式临时保存、全服务单个读取任务、五分钟总时限；ZIP目录最多100000项/总声明解压4GiB，清单最多16MiB并复核CRC及长度，只读取根清单、不解压其他文件或运行APK。拒绝AAB/APKS、路径、附加参数、重复/加密清单和无效包名。
- 专用二进制接口 POST /api/android/apk/inspect 保持真实来源/Host/同源及专用头；仅返回文件名、大小与包名。取消、断连、后台、离页、换文件和服务退出清理等待、临时包与旧结果；内容不入数据库、备份或操作日志。
- 两产品共享实现与离线测试；验证真实二进制清单、ZIP/CRC/资源限制、无ADB可用、HTTP保护及浏览器读取/复制/错误恢复/取消与明暗主题。包名读取不代表签名或可安装性验证。

## F-ADB-001 补充：多 APK 安装队列（TASK-042）

- 同一面板选择1～20个完整APK与1～20台在线设备；支持单设备多APK及多设备多APK，每台按文件选择顺序串行、最多两台设备并行。确认列出全部文件、大小、设备及安装项数；仅覆盖安装并保留数据，不自动卸载/降级/授权。
- 多文件通过专用受保护二进制端点一次流式上传，每包1GiB、总计4GiB、元数据64KiB；全部结构校验完成后才开始安装。上传总限五分钟、每安装项五分钟、安装队列总限一小时。
- 按设备与文件分别返回实时状态，单项失败继续，取消/断连/后台/离页/退出终止活动及后续任务并清理。失败重选只重试明确失败且仍在线的安装项，不能把原成功的组合重复安装；取消不能回滚。无数据迁移。

# 功能规格说明书（FUNCTIONAL_SPEC）

## F-KB-018 项目管理（TASK-075、TASK-076）

主导航在知识库后提供“项目管理”。用户可查看全部项目或选择单个项目，在列表与看板之间切换。项目支持规划中、进行中、暂停、已完成和已归档，状态由用户设置。概览按完成待办数除以总数计算进度，并展示逾期和最近更新。待办可保存优先级、截止日期、文字负责人及标签，并按这些字段筛选。日期按浏览器本地日历判定，本周为周一至周日。看板分为待处理、处理中和已完成。勾选即归档，恢复回到原处理阶段。支持确认删除待办和空项目。原备份仍可导入。

SQLite追加迁移012（kb_projects、kb_project_todos），项目与待办独立版本锁，最多100项目、5000待办，名称80字、项目说明1000字、问题200字、处理说明2000字，正文合计8MiB。同名项目按规范化名称拒绝重复，旧版本修改/删除不覆盖新记录。失败保留输入与明确提示，切换/刷新/关闭前保护未保存编辑，离页取消请求并阻止旧结果回填；不把团队数据存localStorage。

专用API为/api/project-todos，128KiB JSON解析器在全局解析前注册，保持真实来源/Host/同源与X-Toolbox-Project-Todos: 1校验；错误日志不含项目与待办正文。JSON、压缩JSON及全量ZIP备份增加可选project_todos字段与计数，旧备份缺省兼容；导入先校验全部记录/关联/归档时间，再事务合并，项目按ID或名称复用、待办按ID去重，不覆盖现有内容，合并后仍受同一限额约束。验收覆盖升级保留旧资料、重启、编辑冲突、归档恢复、删除保护、备份往返/回滚、隔离浏览器失败重试及明暗1280/1700布局。

## F-MEDIA-003 视频压制与模板扩展（TASK-073）

视频处理独立为参数与批量队列两栏，参考[小丸工具箱](https://maruko.appinn.me/)的压制、音频和字幕设置组织，不复制其程序或商标。保留MP4/截取/MP3/GIF；增加H.264 CRF或平均码率、编码速度、最大宽高/不放大、原帧率或指定帧率、H.264 profile/level、AAC码率/采样率/声道或静音，以及外置UTF-8 SRT/ASS字幕烧录。只提供结构化选项，不接受命令行、服务器路径或自由滤镜；最多8视频逐项处理，失败继续，可停止及重新处理失败项。显示真实上传百分比，编码阶段明确等待，不伪造实时编码进度。

内置Unity 1080p/30fps、Unity 720p/30fps、通用均衡/高画质/小体积模板，Unity采用MP4/H.264 Main 4.1/YUV420P/AAC双声道48kHz/faststart；实际平台解码仍须Unity项目测试。支持应用、自定义保存、改名更新、另存和确认删除；内置只读。模板最多50个、名称40字且不重名，服务端data/video-presets.json版本1原子保存并检查乐观版本，重启及不同浏览器可读取；损坏拒绝覆盖、保存失败保留草稿。仅存压制选项，裁剪时间、文件、字幕原文和路径不写配置/日志/团队内容备份。

视频1GiB、字幕2MiB/UTF-8且有界行数与长度、输出256MiB、每项十分钟、两个活动请求；随机私有暂存且固定字幕名，不接受字幕附件字体/图形；结束/取消/断连/后台/离页/退出回收。API保持真实来源/Host/同源和X-Toolbox-Media专用头，模板JSON8KiB在全局JSON之前注册；不改变SQLite。测试覆盖参数拒绝、模板持久化/冲突/删除/损坏保护、真实FFmpeg压制/媒体属性/字幕像素、HTTP附加字幕及取消清理、明暗布局/下拉/弹窗/队列与最终包。

## F-NET-005 FTP／FTPS／SFTP 客户端（TASK-070）

完整工具箱增加真正的远程文件客户端，参考FileZilla连接栏、双栏文件列表与底部传输队列布局，复用本项目PrimeVue和液态玻璃主题，不复制FileZilla源码或商标。用户输入协议、主机、端口、用户名和密码连接；FTP明确提示明文，FTPS使用显式TLS并验证证书，SFTP先读取服务器SHA256指纹，经用户核对确认后才发送认证信息。密码、会话票据及指纹只在本轮内存，不落浏览器存储、配置、日志或团队备份。

左侧为浏览器主动选择的本地待传文件（手机/其他电脑上是该浏览器本机），右侧为远端目录、面包屑及文件名称/类型/大小/修改时间，支持刷新、搜索、进入/返回目录、创建目录、重命名、删除单个文件/空目录、上传与下载。修改远端内容需明确目标及确认；默认拒绝覆盖，同名覆盖须单独勾选并确认。上传流式中转到服务器随机远端暂存名，成功后提交，失败/取消尝试清理；网络断开无法保证远端清理时明确提示。下载以短期单次票据交给浏览器流式保存。

每批最多100文件、单项1GiB，总计4GiB；最多4会话及2活动传输，每会话串行命令，列表2000项并限制响应大小。连接/命令15秒、文件15分钟/90秒无进展，离页/后台/断连/服务退出关闭连接，90秒无心跳过期；队列显示真实已传字节、速率和成功/失败/取消，不将上传到工具箱的比例冒充远端保存完成。API保留真实来源/Host/同源/专用头，仅精确上传接受二进制；协议参数与远端路径严格校验，拒绝命令注入和任意Shell，凭据不入错误响应。

测试使用隔离目录、临时FTP/FTPS及真实SSH2协议SFTP服务器和浏览器，覆盖证书与指纹、认证失败、实际文件字节、目录操作/确认、同名保护、并发/限额、进度、取消/断连/超时/退出、凭据不落盘、双栏布局和既有工具回归。不连接用户真实服务器；不同FTP厂商/编码和服务器权限另行试用。

## F-NET-004 局域网文件共享（TASK-069）

完整工具箱提供类似FTP的网页目录共享。用户填写工具箱电脑的现有绝对文件夹路径，选择只读或允许上传、1/8/24小时期限并确认后开启；最多8个共享。生成局域网链接和二维码，独立手机页面支持目录浏览、面包屑、当前目录搜索、文件下载；可上传共享还支持批量文件上传、逐项进度、取消与新建文件夹。同名自动加序号，不覆盖原件，不提供删除或任意命令。管理页也可直接浏览共享。

共享及随机访问票据仅服务内存保存，票据只在链接fragment及专用头传输；离开管理页不关闭共享，停止/到期/退出使链接失效并取消未完成传输，已完成文件保留。目录与文件不进入资源库、SQLite、备份或浏览器存储。管理接口沿用工具箱的受控内网信任边界，不作为独立账号权限系统；Local模式仍可本机使用并明确提示手机访问需Lan。

固定共享根目录，拒绝磁盘根、UNC/设备路径、越级、符号链接/目录联接、特殊设备名与文件硬链接；逐级复核根及目标身份。单目录最多2000项，上传每批最多100项、单项1GiB、全服务2个并行上传和4个下载；流式随机暂存、SHA256、10分钟/90秒无数据时限。下载使用一分钟单次票据及原生浏览器附件流，避免大文件整体进入网页内存；上传/下载停止后清理暂存，失败保持原件并反馈原因。网页请求保留真实来源/Host/同源及专用头，下载正文仅精确票据端点放行。

验收使用临时目录与隔离服务/浏览器：真实文件上传下载和摘要、目录隔离/链接/同名/权限、并发/超时/停止/断连/到期、旧链接失效、手机360/390/768及桌面明暗布局；执行全后端、前端单元/构建、分组/排序及LAN回归。实际设备扫码另验。

- 自定义菜单和分组弹窗挂到 body；选择项包含清晰的未选/选中/焦点/禁用态，支持中文、键盘、搜索（多选及长列表）和焦点返回。浮层不能被玻璃容器或拖动卡片裁切。

## F-KB-012 SOP模板与执行清单（TASK-063）

知识库增加“SOP检查清单”入口，独立管理模板与执行历史。模板包含名称、说明及1～50条有序步骤，可新增、编辑、上下移动步骤及确认删除；名称1～80字、说明2000字、每步骤500字，最多200模板。开始执行时复制模板名称、版本和步骤，形成独立记录；逐项勾选、进度和执行备注保存至服务器，关闭网页后可继续。全部步骤完成后才能主动结束本次执行，完成记录只读；每次再次执行创建新记录，编辑或删除模板不得改变历史快照。

执行记录最多1000条、备注2000字，模板与记录正文总计最多8MiB；历史分页并支持未完成/已完成筛选。模板和记录均使用版本冲突校验，多浏览器旧版本不能覆盖新内容；创建执行通过请求UUID防止网络重试重复建立。删除模板/记录分别确认，删除模板保留历史。SQLite迁移010，团队内容不存localStorage。JSON/压缩及全量ZIP备份携带可选SOP字段，旧备份兼容；导入先校验全部字段，同ID或同名模板不覆盖，历史按独立ID去重。

专用API使用真实来源/Host/同源保护、`X-Toolbox-SOP: 1`和128KiB JSON上限；错误保留草稿，切换或离页取消请求并阻止旧结果回填，操作失败明确反馈。弹窗body Teleport并支持键盘，明暗主题及1280/1700布局清晰。验证包括真实迁移与重启持久化、模板修改/删除后的历史隔离、勾选与完成限制、版本冲突、确认删除、幂等创建、备份往返及隔离浏览器全流程。双向链接、数据库多视图等借鉴功能另由TASK-064～067定义，见知识库工作台契约。

## F-CALC-001 快速计算（TASK-062）

完整工具箱新增“快速计算”：输入基准、浮动比例（倍率0.02或百分比2表示2%）、上下每组数量2～500及小数位0～12，分别在下限至基准、基准至上限均匀取点，每组包含两端点。默认27.75、0.02、每组10项、6位小数；对应下限27.195、上限28.305，默认结果与用户示例一致。浮动幅度为基准绝对值乘比例，支持负基准、零及跨零区间；比例0～1000%。使用十进制整数/有理数计算，只在显示时四舍五入，出现显示重复值时说明精度限制。

支持复制两组结果、命名保存、列表重用、确认删除。保存参数至服务端SQLite（迁移009），不把团队数据存浏览器；计算结果按同一算法重建。同名同参数重复保存返回原方案，不同参数同名提示另取名；最多500方案。快照和全量备份携带方案，旧备份缺少该字段时兼容，不覆盖同名既有方案。接口复用真实来源/Host/同源保护与专用头、受限JSON及取消/超时；页面切换/输入变化防止迟到结果回填，错误保留输入，删除失败保留记录。验收包含示例/小数舍入/端点/负值/限额、持久化重启/迁移/备份、接口边界、隔离浏览器保存复用删除、错误恢复及明暗布局。

## F-UI-008 按钮水波纹反馈（TASK-061）

按钮、侧栏导航、工具标签及可操作页面树在实际点击后提供一次180ms内的轻柔水波纹；指针从点击位置扩散，键盘操作从中心扩散。选中状态继续由原有底色、文字及描边表达，不以动画替代状态。禁用控件、输入框、拖拽和第三方画布/编辑器不加反馈，不改变原事件、确认或工具执行逻辑。

效果通过 body Teleport 独立绘制，禁止拦截事件或改变控件布局/溢出；快速点击有数量限制、到时移除，目标消失、滚动、离页或后台及时回收。支持明暗主题、原有键盘操作，减少动态或透明度时不绘制。仅前端变化，无依赖、数据库或真实知识库内容变更。使用临时浏览器验证原生指针/键盘、选中状态、弹窗、清理与降级，并回归视觉、工具分组/排序及安卓流程。

## F-UI-007 液态玻璃视觉（TASK-060）

TASK-071按用户偏好调整暗色：整体采用黑灰纯色背景，页面、侧栏、卡片、输入和菜单以明度/细边框区分层级，去掉蓝紫光晕及暗色背景渐变；浅色继续原有玻璃材质。主题切换/持久化、选中/焦点、减少动态/透明度、菜单和日志文字对比度保持可用，浏览器主题栏与CSS背景一致。

完整工具箱参考苹果液态玻璃的边缘反光、柔和阴影和圆润控件，统一主框架、导航、工具标签、卡片、按钮、输入框及弹窗；浅色使用通透环境光，暗色遵循TASK-071黑灰纯色约定。继续使用 Vue/CSS 与主题变量，不引入图片、滤镜脚本、外部资源或持续动画。背景模糊集中在大型玻璃面板及独立弹窗，内层卡片与按钮不叠加模糊；原生下拉菜单、日志和正文保证对比度。

支持系统减少动态效果、减少透明度偏好和无 backdrop-filter 的降级；焦点仍清晰，浮层继续 Teleport 到 body。保持既有布局、分组/标签、安卓收放与所有工具操作。验收覆盖明暗主题、1280/1700窗口、卡片及导航/标签交互、弹窗视口定位、键盘焦点、可读性和视觉降级，使用隔离页面及临时浏览器。

## F-AM-003 实况照片（TASK-048）

- 完整工具箱接收带XMP视频偏移/目录的JPEG动态照片，以及含一张JPEG/HEIC和一段MOV/MP4的LIVP容器。手机上传页可明确开启同名原照片/视频配对，打包为LIVP保存；关闭时维持独立文件。歧义配对不能自动猜测。
- 原件不改写，动态部分由预览管线有界提取；资源预览提供“实况”标识、主动播放/停止、静音默认和动态视频下载。图片详情提供手动重新生成预览入口，用于旧图识别或失败重试，不新建版本。离页、关闭、切换和页面后台必须停止解码，静态预览和原件下载可独立使用。
- 原生浏览器未交付动态文件时明确提示只保存了静态内容，不能把普通照片伪装成实况。HEIC解码或视频转码失败保留原件并显示原因，不保证导回每种手机相册后仍被识别为实况。
- ZIP仅接受有界、未加密、非链接的一图一视频，流式解压并复核CRC；不接收客户端路径。内嵌MP4只按受限XMP偏移和有效BMFF边界识别，不扫描任意视频特征。固定隐藏FFmpeg进程只读取本次临时文件，禁用网络协议并限制时长/尺寸/输出/并发，清理本次临时文件。
- 版本元数据保存实况派生键，无SQLite结构变化；镜像、导出/导入、完整备份和历史版本均保留或重建动态片段。验证解析、配对歧义/取消/限额、HTTP及Range播放、原件字节、导入ID映射和浏览器生命周期，真机相册另验。

### F-KB-001 新建 Markdown 文档

- **价值与优先级**：P0。团队知识沉淀的最小入口，缺失则知识库不成立。
- **目标版本**：v0.1（MVP）。
- **前置与输入**：进入“新建文档”页；输入标题（必填，去首尾空白后 1–100 字符）、正文（Markdown 文本，可为空，上限 1MB）、分类（可选，须为已存在分类）、标签（可选，每文档 ≤10 个）。
- **流程与输出**：提交 → 服务端校验 → 写入持久化存储并生成 id、version=1、created_at/updated_at → 前端跳转文档详情页并提示成功。
- **失败与恢复**：网络/服务错误时前端保留已输入内容（会话内草稿）并允许重试；校验失败返回字段级错误；服务端保证要么完整写入、要么不写入，不留半条数据。
- **安全考量**：正文按原文存储，仅在渲染时安全渲染（见 F-KB-002）；长度与结构在服务端校验。
- **验收标准**：1) 新建后列表与详情可见；2) 空/纯空白标题被拒并提示；3) 模拟断网保存失败后内容不丢失、重试可成功；4) 刷新页面与服务重启后文档仍存在（服务端持久化）。

### F-KB-002 编辑文档（含保存冲突处理）

- **价值与优先级**：P0。知识库的核心维护路径。
- **目标版本**：v0.1（MVP）。
- **前置与输入**：已存在文档；编辑页加载标题/正文/分类/标签及当前 version。
- **流程与输出**：修改后保存并携带 version；服务端比对一致则写入、version+1、更新 updated_at；不一致返回 409 及服务端当前内容。编辑页提供与最终渲染一致的 Markdown 预览。
- **失败与恢复**：冲突时提示“文档已在别处被修改”，提供【加载最新（丢弃本地修改）】与【基于最新内容覆盖保存（需再次确认）】两个选项；MVP 不做自动合并。普通保存失败的重试策略同 F-KB-001。
- **安全考量**：Markdown 渲染必须安全渲染：默认转义 HTML、仅白名单语法可用，防止存储型 XSS。
- **验收标准**：1) 保存后详情页与首页 updated_at 变化；2) 两个会话先后保存同一文档，后者收到 409 与明确选项；3) 选“加载最新”后内容与服务端一致；4) 含 `<script>` 的 Markdown 保存后渲染不执行脚本。

### F-KB-003 删除文档

- **价值与优先级**：P0。
- **目标版本**：v0.1（MVP）。
- **前置与输入**：已存在文档；删除入口位于文档页。
- **流程与输出**：点击删除 → 二次确认（显示文档标题）→ 服务端删除（含标签关联）→ 列表、搜索、最近更新均不再出现。
- **失败与恢复**：删除失败提示并可重试；确认框可取消。误删恢复走备份（F-OPS-002）；MVP 无回收站（回收站属后续增强，不承诺）。
- **安全考量**：二次确认防误触；接口仅接受已知文档 id。
- **验收标准**：1) 删除后列表/搜索/最近更新均不出现该文档；2) 取消确认则不删除；3) 与 F-OPS-002 联测：备份恢复演练可找回删除前内容。

### F-KB-004 分类管理

- **价值与优先级**：P1。横向组织文档。
- **目标版本**：v0.1（MVP）。
- **前置与输入**：分类名称（1–30 字符，同级唯一）；MVP 仅一级分类、不嵌套、上限 50 个。
- **流程与输出**：新建/重命名/删除分类；重命名不影响文档归属；删除分类时其文档 category_id 置空（变为“未分类”），确认提示受影响文档数。
- **失败与恢复**：重名/超限返回明确错误；操作失败可重试。
- **安全考量**：名称服务端校验，渲染转义。
- **验收标准**：1) 新建/重命名后列表正确反映；2) 删除分类后原属文档显示“未分类”；3) 重名被拒并提示。

### F-KB-005 标签管理

- **价值与优先级**：P1。跨分类检索的轻量维度。
- **目标版本**：v0.1（MVP）。
- **前置与输入**：编辑文档时输入标签名（1–30 字符）；保存时自动去空白、去重，英文字母统一小写合并。
- **流程与输出**：保存文档时同步文档-标签关联；列表页可按标签过滤（多个标签采用 AND 语义（同时包含所有所选标签），与分类筛选同时生效）；删除标签即解除全部关联。
- **失败与恢复**：超过单文档 10 个标签时提示；失败可重试。
- **安全考量**：名称服务端校验，渲染转义。
- **验收标准**：1) 添加/移除标签后正确显示；2) 重复标签自动合并；3) 按多个标签过滤仅返回同时包含全部所选标签的文档；4) 超过 10 个被拒。

### F-KB-006 搜索

- **价值与优先级**：P0。找回知识的主要手段。
- **目标版本**：v0.1（MVP）。
- **前置与输入**：搜索框输入关键词（非空，去首尾空白）。
- **流程与输出**：服务端按标题+正文匹配（实现方式待决策：SQL LIKE 或轻量倒排索引，见 ARCHITECTURE），结果按 updated_at 倒序、分页返回，展示标题、摘要片段、分类、标签。
- **失败与恢复**：空关键词不发起查询；查询失败提示可重试；无结果显示空状态文案而非报错。
- **安全考量**：关键词须参数化/转义处理，防止注入（依存储技术实现）。
- **验收标准**：1) 命中标题或正文的文档出现在结果中；2) 无结果显示空状态提示；3) 结果按更新时间倒序；4) 特殊字符关键词不引发错误或注入。

- **实现方式（2026-10-23 更新）**：FTS5 全文索引 + 自研分词。
  - 分词：中文按 2-gram 切分（「部署指南」→ 部署 署指 指南），英文/数字按整词保留并转小写。
    原因：SQLite 内置的 unicode61 把连续 CJK 当成一个 token（搜「部署」命中不了「部署指南」），
    trigram 最短 3 字符（搜「部署」这类双字词无结果），ascii 只处理 ASCII。
  - 排序：BM25 相关性优先，相关度相同时按更新时间倒序。
  - 索引在应用层维护（写入/更新/删除文档时同步），服务启动时比对行数，漂移则自动重建。
  - 降级：若 SQLite 构建不含 FTS5，自动退回 LIKE 实现，搜索不中断。

- **验收标准**：1) 重启服务后数据保留；2) 导出文件包含全部文档与元数据；3) 团队成员在另一浏览器/设备可见相同数据（证明不是 localStorage）。

### F-KB-008 首页最近更新

- **价值与优先级**：P1。默认入口反映知识库活跃度。
- **目标版本**：v0.1（MVP）。

- **流程与输出**：按 updated_at 倒序展示最近更新的文档（标题、分类、标签、更新时间），默认 20 条，“查看更多”分页加载。
- **失败与恢复**：加载失败显示错误与重试；空库显示引导新建的空状态。
- **安全考量**：渲染转义。
- **验收标准**：1) 更新任一文档后其排到首位；2) 空库显示空状态；3) “查看更多”分页可用。

### F-KB-009 文档引用资源库

- **价值与优先级**：P1（打通知识库与资源库两个子系统）。
- **目标版本**：v0.2。
- **前置与输入**：资源库中的资源（Asset）；知识库文档正文（Markdown）。
- **流程与输出**：编辑器提供「插入资源」入口 → 弹窗列出资源（可搜索）→ 选中后
  在光标处插入**标准 Markdown 图片语法** `![资源名](/api/assets/files/<资产id>/<kind>/auto)`：
  - 图片类资源用 `preview`（缩略后的预览图，避免正文里塞几百 MB 的原图）；
  - 其他类型用 `original`（模型、纹理等本就要下载使用）。
- **版本语义**：pointer 用 `auto` —— 有发布版就用发布版，没有则退回最新版。
  资源一旦发布，文档里的引用自动跟进到正式版。
- **失效处理**：引用的资源被删除或文件丢失时，渲染为带 alt 文本的占位块
  （说明「引用的资源已删除或不可用」），而不是浏览器原生破图。
- **安全考量**：引用 URL 是同源相对路径，渲染仍走既有 sanitize-html 白名单，
  不引入新的 HTML 标签或协议。
- **验收标准**：1) 编辑器可选资源并插入引用，保存后正文含引用语法；
  2) 阅读页有效引用显示为图片；3) 失效引用显示占位块且保留原 alt 文本；
  4) 引用不削弱既有的 XSS 白名单与外链 rel 保护。

### F-NAV-001 工具导航与卡片框架

- **价值与优先级**：P1（框架性）。为后续小工具预留统一入口。

### F-KB-010 文档回收站

- **价值与优先级**：P0（数据保护）。与「备份不含资源文件」同类 —— 让用户以为自己有退路，实际没有。
- **目标版本**：v0.1（MVP 补充）。
- **前置与输入**：删除文档的操作（单条删除、批量删除）。
- **流程与输出**：
  - 删除 = **软删除**：只打 `is_deleted` 标记，**不物理删除数据**，子页面与标签关联全部保留。
  - 删除父页面时，整棵子树一并移入回收站（与旧版级联删除的可见行为一致）。
  - 知识库提供「回收站」入口（`/kb/trash`），列表按删除时间倒序，显示标题、分类、标签、
    正文摘要、删除时间、子页数。
  - 每条可「恢复」或「永久删除」；顶部可批量恢复、批量永久删除、清空回收站。
  - 恢复：连带整棵子树恢复，标签与正文完整带回，并重建全文索引（恢复后即可被搜索命中）。
  - 永久删除：物理移除，**必须二次确认**（接口要求 `confirm=1`），且**只允许删已在回收站里的文档**。
- **失败与恢复**：
  - 恢复时若上级页面已不存在或仍在回收站，该文档**自动提升为顶层**并在提示中告知用户，
    避免挂在一个看不见的父节点下成为孤儿。
  - 永久删除时，**已单独恢复正常的下层文档不受影响**（会被摘为顶层），
    不会被 `ON DELETE CASCADE` 连带删除。
  - 永久删除的影响面如实计入返回值（含随子树一起清掉的回收站文档），不虚报数量。
- **安全考量**：已删文档对正常列表、详情、搜索、页面树全部不可见，
  不可通过直链或接口绕过（详情报 404、编辑报 404）。
- **验收标准**：1) 删除后正常列表/详情/搜索/页面树均不可见，回收站可见；
  2) 恢复后正文、标签、可搜索性完整；3) 恢复时父级不可用则提升为顶层；
  4) 永久删除需二次确认且不带走已恢复的子页；5) 备份往返保留回收站内容与删除状态。

### F-AM-001 资源集合（Packs）

> 编号说明：资源管理子系统（TASK-010 起）此前未在本文档登记特性条目，
> 只在 DEVELOPMENT_PLAN 中有任务拆分。这是文档缺口，
> 补全整个资源管理的特性规格需要单独一轮梳理；本条目只登记 TASK-017 新增的能力，
> 不假装资源管理已完整覆盖。

- **价值与优先级**：P1（交付能力）。文件夹回答「归哪儿管」，集合回答「这次要交付哪些」。
- **目标版本**：v0.1（资源管理补充）。
- **前置与输入**：资源库中的资源（Asset）；用户对一组资源的临时编组需求。
- **流程与输出**：
  - 资源页提供「集合」入口；集合列表显示名称、描述、成员数、更新时间。
  - 可新建 / 重命名 / 删除集合，集合名唯一（重名给出可读提示而非数据库报错）。
  - 集合详情显示成员资源的缩略图、名称、类型、最新版本号。
  - 资源页批量操作提供「加入集合」：输入集合名，已存在则加入、不存在则自动创建。
  - 可从集合移除资源（多选），也可删除整个集合。
- **语义边界（最容易误解的地方）**：
  - 集合是**视图不是容器**：一个资源可同时属于多个集合；从集合移除或删除集合，
    **都不影响资源本身**、不影响它的文件夹归属、也不影响它所在的其他集合。
  - 集合与文件夹互补而非替代：文件夹是一棵树（一个资源只能待在一个位置），集合是多对多。
- **失败与恢复**：
  - 软删的资源不出现在集合里，从回收站恢复后**自动回到原集合**（无需额外维护成员关系）。
  - 资源永久删除时成员行由数据库级联清理，不留悬空引用。
  - 不能把回收站里的资源加进集合（会显示「3 个资源」但点进去只有 2 个）。
- **安全考量**：集合操作不涉及文件读写，只维护元数据关联。
- **验收标准**：1) 能建集合、加资源、看成员数；2) 一个资源可属多个集合；
  3) 重复加入幂等；4) 删集合不删资源、移出集合不删资源（界面对此有明确说明）；
  5) 软删资源离开集合、恢复后回到集合；6) 永久删除资源后成员行不悬空。

- **价值与优先级**：P0（数据安全）。
- **目标版本**：v0.1（MVP）。

- **验收标准**：1) 导出 → 清空 → 恢复后数据与导出前一致（演练一次并记录）；2) 恢复操作有覆盖确认。

#### 备份范围（2026-10-23 补充）

备份分两种范围，**界面必须明示区别** —— 此前只有「仅文档」一种，
用户点「导出备份」以为数据安全了，实际只保住文字：

| 范围 | 格式 | 含文档 | 含文档图片 | 含资源文件 |
|---|---|---|---|---|
| 全量备份 | ZIP | 是 | 是（`data/uploads/`） | 是（原图 / 预览图 / 缩略图） |
| 仅文档 | JSON / JSON.GZ | 是 | 否 | 否 |

- 全量备份为**流式**打包，不把大文件读进内存（资源可能是数百 MB 的 GLB）。
- 恢复为**合并模式**：不删除既有数据；文档按「同父级下同名」跳过，
  资源重新分配全部 id，同名文件夹跳过。恢复前需用户确认。
- 验收标准补充：3) 全量备份导出 → 清空 → 恢复后，**文档、图片、资源文件均与导出前一致**。

### F-OPS-003 自动更新

- **价值与优先级**：P1（降低「必须升级时没人升」的风险）。
- **目标版本**：v0.2。
- **前置与输入**：一个**可配置的更新源**（静态文件托管即可），其中包含
  `manifest.json` 与对应的发布包 ZIP。
- **流程与输出**：
  1. 「检查更新」读取 `manifest.json`，与本地版本比对；
  2. 「下载并安装」→ 下载包 → 校验 SHA256 → 解压 → **用包内自带的 node.exe 自检原生模块**；
  3. 通过后**先备份全部数据**，再由独立的 `apply.cmd` 在服务退出后换文件并重启；
  4. 新版本启动成功后清除 `pending` 标记；标记仍在则自动回滚到上一版。
- **更新源形态（TASK-036）**：未保存配置时默认使用本项目 `https://github.com/GuiYe314/team-toolbox/releases/latest/download`；直接粘贴 GitHub 仓库 HTTPS 地址（含 `.git`）或 Releases 首页时，转换为对应的最新正式发布资产目录。只读取发布清单及完整 ZIP，不执行 git pull。
  保留 `http(s)://` 静态目录、清单文件、本地/共享目录；环境变量优先，已有自定义配置及显式关闭继续生效。设置页可使用项目源或关闭更新，切换源后不显示旧源的检查结果。只有主动检查才访问网络，安装仍需确认并重启，不宣称零中断更新。
- **更新代理（TASK-036）**：清单和 ZIP 下载共用专用代理，优先代理环境变量及 NO_PROXY，其次 Windows 当前用户手动 HTTP/HTTPS 代理及绕过列表；回环直连，不执行 PAC，不改变其他工具或系统代理。代理错误明确反馈，凭据不回传、不落盘；保持 TLS 校验和有界下载。
- **后台更新执行（TASK-036）**：文件替换脚本不依赖控制台代码页，Unicode 路径及中文启动文件名通过子进程环境传递；重启不保留 CMD 窗口。发布前在独立副本验证数据备份、替换成功、启动失败回滚和进程清理。

- **失败与恢复**：哈希不符 → 丢弃下载文件，不安装；包结构不全或自检不过 → 在动任何
  文件之前失败；换文件失败或新版本起不来 → 自动回滚，并留下 `ROLLBACK.txt` 供界面提示。
- **安全考量**：安装动作要求 `confirm=1`；包必须与清单声明的 SHA256 一致；
  解压防路径穿越；换文件**排除 `data/`**，用户数据永不参与替换。
- **验收标准**：1) 四种界面状态（未配置 / 已最新 / 有新版 / 清单损坏）均正确呈现；
  2) 哈希不符时不留下任何包文件；3) 包结构不全与自检失败均在动文件前被拒；
  4) 换文件后用户数据完好、新代码生效；5) 新版本未确认启动时自动回滚且数据完好。

### F-ADB-001 安卓无线调试连接管理

- **右侧模块收放（TASK-059）**：常用命令、APK 包名、APK 安装、Unity 文件、手机屏幕和设备日志六个面板默认展开，各自提供“收起／展开”按钮并支持键盘操作。折叠仅隐藏正文，保留设备、文件、筛选及结果，不卸载组件、不取消正在执行的操作；标题继续显示读取、安装、刷新或采集状态。收放状态仅在本次页面内存中维护，刷新或重新进入恢复展开；原配置变化、切换设备、后台与离页的清理规则继续生效。
- **来源与范围**：2026-11-05 用户明确选择无线连接、配对和设备管理，作为独立增强 TASK-019，不改变既有 MVP 门槛。
- **前置**：工具箱服务器安装 Android SDK Platform-Tools；手机与服务器在同一局域网，Android 11 及以上开启无线调试。
- **流程**：输入服务器上的文件夹后，工具箱有界递归搜索 `adb.exe`；唯一结果自动检查版本并配置，多个结果由用户选择，不存在时明确提示。兼容已有可执行文件配置。设备列表提供 USB/无线/模拟器及授权状态、IPv4:端口连接、mDNS 连接/配对服务搜索、六位码配对、确认后断开单台无线设备。
- **扫码配对（TASK-020）**：生成符合 Android 官方协议的临时二维码，手机通过“无线调试 → 使用二维码配对设备”扫描；按二维码随机服务名严格匹配 mDNS 配对服务，自动配对，再识别同一手机的连接服务并连接、刷新设备。二维码两分钟有效，可取消或重新生成；页面离开、到期或失败后清理凭据。不会自动配对其他发现的设备。
- **页面整理与常用命令（TASK-021）**：准备步骤、配对说明及故障处理收进点击后打开的帮助弹窗；ADB 文件夹搜索、候选选择与清除配置统一放在设置页，调试页提供设置入口。增加内置常用命令及结果展示：设备信息、电池、屏幕、第三方应用列表、前台活动、网络地址和按键、重启。仅允许服务端定义的命令 ID 与参数，每次执行前重新验证明确目标为 `device`，自动插入 `-s`；重启必须二次确认。输出仅保留在当前页面，不持久化，不提供自由 Shell 或卸载命令。
- **双栏与日志（TASK-022）**：ADB 设置改为与帮助相同的弹窗，调试页和设置页入口复用同一配置组件，保存后调试页刷新配置。左侧集中二维码、连接、服务搜索及设备列表，右侧为常用命令和实时设备 Logcat。日志必须明确选择在线设备，以固定 `adb -s <serial> logcat -v threadtime -T 100` 参数读取，支持开始/停止、最低级别与关键词筛选、自动滚动和清空显示；不清除设备日志。切换设备、页面离开、配置变化或对应设备断开时结束采集；不再轮询的会话超时结束。服务端缓存最多 2000 条或 1 MiB，浏览器最多 2000 条，单行有长度上限，不自动落盘。安卓模块下拉菜单提供明暗主题下不透明的菜单底色、清晰文字、选中和焦点状态。
- **单应用运行与日志（TASK-023）**：在日志区切换“指定应用”，从明确在线设备读取已安装包名并搜索、选择；选择后读取运行状态、主进程及 `包名:子进程` 的 PID，支持手动刷新。进程存在表示运行中，不代表在前台。应用日志会话只把当前匹配 PID 的日志放入内存及返回浏览器；采集中约每两秒复查进程，应用未运行时等待，重启后跟随新 PID。保留全部设备日志模式，不自动启动、停止或修改应用，不采集 CPU/内存性能指标。应用及运行状态不持久化；参数校验、超时、取消、明确设备、日志缓存和生命周期约束沿用 TASK-022。短暂进程或自定义非包名前缀进程的日志可能无法捕获，帮助中明确范围。

- **接口与验收**：`GET /api/network-speed/snapshot` 复用 Local/Lan 真实来源、Host 和同源规则，拒绝附加参数且禁止缓存。离线测试覆盖差值/精度、网卡生命周期、异常/有界输出/超时/多页面共享/退出及访问约束；前端构建及隔离浏览器覆盖入口、曲线/选择、暂停/隐藏/切换/迟到/错误恢复与明暗主题。另对本机真实计数只读冒烟，不把合成流量当真实带宽验证。

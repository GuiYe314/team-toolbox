- **导出格式菜单**：`GET /backup/export?format=gz` 返回原始 gzip 字节（**刻意不设 `Content-Encoding: gzip`**，否则浏览器自动解压后拿不到可保存的压缩流）；前端下拉菜单二选一。导入端按 **gzip 魔数**（非扩展名）识别，用浏览器内置 `DecompressionStream` 解压。

## 2. 任务明细

### TASK-001 技术栈决策与项目脚手架
- **交付物**：技术栈决策记录（更新 ARCHITECTURE 待决策清单：服务端语言/框架、持久化引擎、前端框架、Markdown 编辑器组件、安全渲染方案、搜索实现）；项目脚手架与目录结构；env.example；经验证后的本地启动说明（写入 USER_GUIDE）。
- **覆盖特性**：F-OPS-001（部分）。
- **依赖**：无。
- **验证**：决策记录完整且含理由；启动命令实际执行成功，输出摘要记入 PROJECT_STATUS。
- **完成条件**：待决策清单 MVP 必选项全部“已决策”；env.example 存在且 .env 被忽略。

### TASK-002 服务端基础与持久化层
- **交付物**：API 服务骨架；数据模型（Document/Category/Tag/DocumentTag，见 ARCHITECTURE 第 3 节）；持久化读写实现；version 字段与乐观并发基础。
- **覆盖特性**：F-KB-007、F-OPS-001（部分）。
- **依赖**：TASK-001。
- **验证**：健康检查接口；写入 → 重启 → 读取一致性检查；存储层条件写入冲突复现步骤（HTTP 409 待 TASK-003）。
- **完成条件**：重启后数据保留；存储层版本冲突可检测。

### TASK-003 文档 CRUD API
- **交付物**：新建/读取/更新/删除接口；字段校验与统一错误码；409 冲突语义；分类/标签关联的读写支持。
- **覆盖特性**：F-KB-001、F-KB-002（API 部分）、F-KB-003。
- **依赖**：TASK-002。
- **验证**：接口级用例覆盖各特性验收中不依赖 UI 的条目（可用脚本或自动化测试）。
- **完成条件**：上述条目全部通过并记录证据。

### TASK-004 前端应用框架与导航布局
- **交付物**：页面骨架（首页、知识库列表、文档详情/编辑占位）；导航；“小工具”卡片区块；统一空状态组件。
- **覆盖特性**：F-NAV-001、F-NAV-002。
- **依赖**：TASK-001。
- **验证**：本地服务下页面可访问；卡片与空状态展示正确、无假数据。
- **完成条件**：F-NAV-001/002 验收标准全部通过。

### TASK-005 Markdown 编辑与文档页面
- **交付物**：新建/编辑页（Markdown 输入、预览、保存、失败重试与草稿保留）；删除入口与二次确认；保存冲突提示与两个处理选项。
- **覆盖特性**：F-KB-001、F-KB-002、F-KB-003（UI 部分）。
- **依赖**：TASK-003、TASK-004。
- **验证**：按 FUNCTIONAL_SPEC 验收标准在浏览器逐条手工测试并记录结果（含断网重试与双会话冲突场景）。
- **完成条件**：F-KB-001/002/003 验收全部通过。

### TASK-006 分类与标签
- **交付物**：分类与标签的界面与交互（编辑页选择/输入、列表过滤、分类管理操作）。
- **覆盖特性**：F-KB-004、F-KB-005。
- **依赖**：TASK-005。
- **验证**：分类重命名/删除迁移、标签去重/过滤、上限拦截等场景测试。
- **完成条件**：F-KB-004/005 验收全部通过。

### TASK-007 搜索
- **交付物**：搜索框与服务端查询实现（方案按 TASK-001 决策）；结果列表（标题、摘要片段、分类、标签、分页）。
- **覆盖特性**：F-KB-006。
- **依赖**：TASK-005（需有可编辑的文档数据）。
- **验证**：预置数据集上的搜索用例：命中、空结果、排序、特殊字符。
- **完成条件**：F-KB-006 验收全部通过。

### TASK-008 首页最近更新
- **交付物**：首页“最近更新”区块（默认 20 条、updated_at 倒序、“查看更多”）与空库空状态。
- **覆盖特性**：F-KB-008。
- **依赖**：TASK-005。
- **验证**：更新文档后排序变化；空库状态；分页加载。
- **完成条件**：F-KB-008 验收全部通过。

### TASK-009 备份导出与恢复
- **交付物**：导出脚本/命令（输出到 backups/ 或配置目录，格式与 F-OPS-002 一致）；恢复步骤文档；备份目录约定（配合 .gitignore）。
- **覆盖特性**：F-KB-007（导出部分）、F-OPS-002。
- **依赖**：TASK-002。
- **验证**：导出 → 清空 → 恢复 → 数据一致性演练一次，过程与结果记入 PROJECT_STATUS。
- **完成条件**：演练成功且有记录；恢复操作含覆盖确认。

### TASK-010 MVP 集成验收（阶段门槛）
- **交付物**：逐特性逐条验收执行记录；遗留问题清单；PROJECT_STATUS 与 CHANGELOG 更新；边界声明核查结果。
- **覆盖特性**：全部 12 项 MVP 特性（复核性覆盖，重点 F-OPS-001/002）。
- **依赖**：TASK-005、TASK-006、TASK-007、TASK-008、TASK-009。
- **验证**：按 FUNCTIONAL_SPEC 验收标准逐条执行；检查文档间链接有效性；核查 README/部署说明的“禁止公网暴露”声明在位。
- **完成条件**：**MVP 完成门槛**——F-KB-001~008、F-NAV-001~002、F-OPS-001~002 全部验收通过；延期特性 F-COL-001/F-SEC-001 及任务 TASK-D01/D02 不计入本门槛。

# team-toolbox 0.1.0

面向受控本机/内网环境的团队工具箱。首个正式发布，包含**知识库**与**资源管理**两个子系统。

> **使用边界**：本版本**未内置认证与权限控制**，按设计只面向受控本机/内网环境，**不得暴露到公网**。详见 [ARCHITECTURE 第 7 节](https://github.com/GuiYe314/team-toolbox/blob/main/docs/ARCHITECTURE.md)。

## 下载

| 资产 | 说明 |
|---|---|
| `team-toolbox-Setup-0.1.0.exe` | Windows 安装包，装到 `%LOCALAPPDATA%\team-toolbox` |
| `team-toolbox-0.1.0.zip` | 便携包，解压即用，无需安装 |
| `team-toolbox-0.1.0-SHA256.txt` | 校验清单，下载后核对完整性 |

**需先安装 Node.js 运行时**（v20.19+ 或 v22 LTS）—— 安装包会在安装前检查并提示。启动后访问 <http://127.0.0.1:3000/> 即可使用；前端与 API 同源，单端口访问。

## 更新内容

### 知识库

- **文档管理**：Markdown 文档的新建、编辑、删除，服务端持久化到 SQLite（启用 WAL 与外键约束）。
- **保存冲突处理**：两会话同时编辑同一文档时，后保存方收到 HTTP 409，并提供「加载最新」与「基于最新覆盖保存」两种选择（覆盖需二次确认）。编辑内容写入 sessionStorage 草稿，意外刷新或断网不丢。
- **分类与标签**：分类支持重命名、删除（删除后文档转为未分类，不连带删除）；标签自动转小写、去重、去空白，单文档上限 10 个。
- **标签组合筛选**：多选标签按 **AND** 语义筛选 —— 必须同时包含所选全部标签才算命中。
- **搜索**：标题与正文关键词搜索，不区分大小写；中文按子串匹配；`LIKE` 通配符统一转义为字面量；结果附摘要片段与分页。
- **首页最近更新**：按更新时间倒序，支持分页加载更多；空库给出引导入口。
- **Markdown 渲染**：服务端白名单净化后输出，防存储型 XSS；脚本不执行。
- **页面树**：文档支持父子层级，移动时防环校验（不能挂到自身或后代之下）。

### 资源管理

- **资源库**：上传、下载、重命名、移动、删除、回收站与永久删除；文件夹树组织；标签与操作记录留痕。
- **版本管理**：追加版本不改既有版本文件；**Latest 与 Published 完全独立** —— 上传只动 latest，发布是移动 published 指针的唯一入口；恢复历史版本通过复制内容生成新版本，latest 只前进不后退。
- **预览管线**：服务端自动生成缩略图与预览图。采用「处理器注册表」架构 —— 管线调度与具体处理分离，新增资源类型只需加一项处理器。

  | 类型 | 产出 |
  |---|---|
  | 图片 | ≤1600px WebP 预览图 + 256×256 缩略图（实测压缩比 84× / 42×） |
  | 3D 模型 | 解析 GLB/glTF，统计 meshes / vertices / triangles / materials / animations |
  | 文本 | 截断预览，JSON 自动格式化 |
  | 音频 | WAV 头解析时长 / 声道 / 采样率 |
  | 视频 | **构建环境无 ffmpeg，如实标记为失败并说明原因** |

- **存储路径**：可设置镜像目录同步到外部盘。主存储永远是服务端权威副本，外部盘不可用不影响使用。
- **导入导出**：ZIP 含 manifest 与文件目录，导出流式写出、导入流式解压并重新分配 id，保留文件夹层级与版本指针关系，同一个包可重复导入。
- **二维码分享**：页面二维码（手机扫后打开当前页面）与每个资源的下载二维码（扫后直接下载）。
- **批量操作**：批量模式开关显式化 —— 只有开启才显示复选框与批量操作条；批量模式下点行只切换选中、不打开详情。

### 界面

- 玻璃拟态视觉体系，深浅双主题，主题切换不重载页面。
- 悬停提示（v-hint）、文档卡片网格、Markdown 帮助面板。
- 所有浮层（弹窗、下拉菜单）统一 Teleport 到 body。

## 已知限制

- **无认证与权限控制** —— 只面向受控本机/内网环境。
- **视频缩略图与封面不可用** —— 需要 ffmpeg，构建环境未安装。视频文件本身上传、下载、版本管理均正常。
- 实时共同编辑（F-COL-001）与账号权限（F-SEC-001）为延期特性，本版不包含。
- 工具箱中除「比例锁定」外的具体小工具均为空状态框架，本版不实现业务功能。

# team-toolbox v0.10.0：工具分组与八类实用工具

工具箱支持个人分组及顶部工具标签，并加入图片、OCR、PDF、视频、安卓投屏、白板、双向互传和开发工具。保留既有知识库、资源库、视频下载、相册、实况照片、Unity 日志及安卓无线调试功能。

- **分组与标签**：分组可新增、改名、排序、启用/停用和展开/收起；工具卡片支持跨组拖拽。顶部固定“工具箱”标签，打开工具新增标签，可切换、关闭及刷新恢复；切换时释放实时工具资源。
- **图片与 OCR**：图片批量缩放、压缩、格式转换、旋转和文字水印；本地中英文 OCR 支持停止、复制和下载。OCR 模型和运行组件随包提供。
- **PDF 与视频**：PDF 合并、页面提取、旋转、水印、图片转 PDF；本地视频压缩、截取、MP4、MP3 和 GIF 输出，支持取消并清理临时文件。
- **安卓流畅投屏**：基于 scrcpy 5.0.1 的网页 H.264 视频、鼠标触控、常用按键和英文输入；需配置 ADB、选择已授权的在线设备。组件随包分发。
- **白板与流程图**：Excalidraw 画布、源文件和 PNG 导出，可主动保存到资源库并读取；不自动上传画布。
- **手机电脑双向互传**：同网段扫码建立短期连接，WebRTC 直传文字和文件，接收确认、进度和 SHA-256 校验；不经过外部中转服务器。
- **开发工具合集**：JSON、Base64、URL、时间戳、UUID、SHA-256、正则、颜色、二维码及 Monaco 文本对比，输入保留在当前页面。
- **入口整理**：移除 FreeLLMAPI 模型对话和 ArtCraft 创作台网页页面，旧地址返回工具箱；保留视频下载。

安卓连续视频需要支持 WebCodecs 的浏览器及安全上下文（如电脑本机 localhost）；普通局域网 HTTP 可继续使用原有截图预览。iOS AirPlay 尚未接入。本版的投屏、扫码和系统相册仍需真实手机兼容验收，合成协议和浏览器验收不代表真机通过。

Windows x64 提供安装器、便携 ZIP、SHA256 校验清单及自动更新 manifest.json，内置 Node 22.22.2、下载/转码组件、scrcpy server 和相关许可；新增 OCR 模型、字体和编辑器使包体积增加。旧版完整工具箱可在“设置”检查项目 GitHub 更新，或停止服务、备份 data 后使用完整发行包升级。无数据库结构变更，独立设备调试版沿用原发行。

仅面向受控本机/局域网。使用步骤见[用户指南](https://github.com/GuiYe314/team-toolbox/blob/main/docs/USER_GUIDE.md)，验证范围与实际发行状态见[项目状态](https://github.com/GuiYe314/team-toolbox/blob/main/docs/PROJECT_STATUS.md)。

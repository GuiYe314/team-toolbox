# team-toolbox v0.9.0：实况照片与启动入口改进

手机扫码上传支持 Live Photo／动态照片的原片保存与网页播放；启动入口会启动未运行的服务，或打开已运行的工具箱网页。保留 v0.8.2 的相册、视频下载、安卓调试和其他工具。

- **实况上传**：接收内嵌 MP4 且带标准 XMP 信息的动态 JPEG，以及 LIVP 文件。iPhone 导出的同名 HEIC/JPG + MOV，可在手机上传页先勾选“将同名原照片 + MOV/MP4 配为一张实况照片”，再同时选择两份原片，打包为一个 LIVP 入库。配对默认关闭，名称歧义时不自动猜测。
- **播放与下载**：电脑资源预览显示实况标识，点击“播放实况”播放、默认静音，支持停止及单独下载动态视频；后台停止，关闭/离页释放。HEIC 实况封面取动态首帧，照片原片保留在 LIVP 中。
- **原件与版本**：动态 JPEG 或 LIVP 原件完整保留；图片详情可“重新生成预览”，为旧图识别实况或失败重试，不增加版本。实况派生内容随版本镜像、导出导入及恢复保留或重建，无数据库结构变化。
- **点击即打开工具箱**：点击启动入口，服务未运行时自动启动再打开网页，已运行时直接打开现有网页。开发版只补起缺少的前/后端，连续点击不重复启动；保留现有 Local/Lan 模式，其他程序占用端口时仍明确提示。

网页动态预览最长30秒、最长边1280像素、最大64MiB；限制只针对预览，不截断原件。配对的每份原片最多256MiB。使用包内 FFmpeg，无需另外安装。

iPhone 的系统相册选择器可能只向网页交付静态图，需要先导出完整照片与 MOV，或选择已导出的 LIVP。无法恢复未提供的视频，不保证所有厂商变种或下载后导回系统相册自动识别。真实 iPhone/Android 扫码及系统相册兼容性尚未验收；验证范围与发行状态见[项目状态](https://github.com/GuiYe314/team-toolbox/blob/main/docs/PROJECT_STATUS.md)。

Windows x64 提供安装器、便携 ZIP、SHA256 校验清单和 `manifest.json`，内置 Node 22.22.2 及原有下载组件和许可。旧版完整工具箱可在“设置”中检查项目 GitHub 更新，也可关闭服务、备份 `data/` 后使用安装器或便携包升级。仅用于受控本机/局域网；独立设备调试版沿用原发行。

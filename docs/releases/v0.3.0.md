# v0.3.0：局域网工具、批量安装与地球光照

本版把全部工具开放到受控局域网，增加多手机 APK 安装、三维地球光照和三个开源工具入口。发布状态与验收证据统一见 [项目状态](../PROJECT_STATUS.md)；详细操作见 [用户指南](../USER_GUIDE.md)。

## 主要变化

- **多手机安装 APK**：选择一个完整 APK 和最多 20 台在线设备，一次上传后逐台安装；实时展示各台结果，单台失败继续下一台，支持重新选择失败设备和取消后续队列。保留单台模式，使用覆盖安装并保留原应用数据，不自动卸载、降级或启动。
- **地球光照**：Globe.gl / Three.js 三维地球、本地地表/夜景/云层贴图、实时太阳直射点、昼夜分界及平行射线；增加光球太阳、赤道和南北回归线与中文标注，支持旋转、缩放、复位及失败降级。
- **Yoinks 接入**：通过服务器上的 yt-dlp 分析单视频、选择格式/MP3、下载、取消与保存临时结果。yt-dlp 需自行安装，高清合并和 MP3 还需 ffmpeg。
- **FreeLLMAPI 接入**：连接服务器本机网关，读取实际可用模型并流式聊天；支持历史、停止和清空，统一 Key 仅存后端内存。需自行运行 FreeLLMAPI 并配置供应商或模型。
- **ArtCraft 接入**：在网页整理、编辑和复制提示词，检测路径并确认启动服务器上的 ArtCraft.exe。原生编辑器在服务器自己的窗口运行，需另行安装及配置。
- **全部工具局域网访问**：Windows 启动器默认 Lan，ADB、APK、屏幕、日志、Unity 日志和三个接入工具均可从同网段访问；保留来源、Host、同源与专用头校验。`启动.cmd /local` 可切换为仅本机。
- **后台启动**：启动器等待进程身份、端口归属和健康检查通过后打开网页，成功后关闭双击产生的 CMD；失败保留提示及日志。`停止.cmd` 只停止本目录服务，排除构建等其他任务。

本机路径、ADB、Unity 搜索、下载组件和 ArtCraft 启动均发生在运行工具箱的电脑上。局域网 HTTP 的复制功能提供兼容处理。地球资源与必要许可随包分发，接入方式和上游许可见 [开源工具说明](../OPEN_SOURCE_INTEGRATIONS.md)。

## 下载与升级

| 文件 | 用途 |
|---|---|
| `team-toolbox-Setup-0.3.0.exe` | Windows x64 安装包，含 Node 和生产依赖 |
| `team-toolbox-0.3.0.zip` | Windows x64 便携包，解压后双击 `启动.cmd` |
| `team-toolbox-0.3.0-SHA256.txt` | 安装包与便携包的 SHA256 及大小 |
| `manifest.json` | 自动更新清单，与便携包同时发布 |

升级前在原版创建完整备份，关闭旧服务后再安装或替换程序。手动升级保留原 `data/`；新增机器配置不在团队备份中，应另行保存。包内自带 Node，无需安装系统 Node 或运行 `npm install`。新版本没有新增 SQLite 迁移。

已有自动更新功能的版本，可在设置中使用更新源 `https://github.com/GuiYe314/team-toolbox/releases/latest/download`；出网受限时也可使用同时保存清单和 ZIP 的内网目录。发布版默认端口为 3000，启动器会输出实际局域网访问地址；防火墙或网络隔离可能影响其他设备连接。

## 验证范围与限制

后端、隔离浏览器及发布包验证记录见 [封版验收报告](../acceptance/V0_3_0_RELEASE_2026-11-10.md)。真实 Android/iPad、另一物理局域网客户端、真实视频网站下载、供应商推理和 ArtCraft 原生生成均未实测，不把替身验收视为真机或上游服务验收。取消安装不能回滚已完成的设备。

项目继续面向可信本机/局域网，尚无账号与权限系统，不支持直接暴露到公网。

## v0.1.1 —— 修复发布包在部分机器上装完起不来

如果你在 v0.1.0 遇到这个报错，本版本就是给你的：

```
Error: 无法打开数据库，请检查配置
    code: 'cannot_open'
    detail: '[Cannot open] The module '...\better_sqlite3.node'
             was compiled against a different Node.js version using
             NODE_MODULE_VERSION 127. This version of Node.js requires
             NODE_MODULE_VERSION 137.'
```

### 原因

`better-sqlite3` 是 Node ABI 敏感的原生模块，随包分发的二进制只能被**同 ABI** 的 Node 加载（ABI 127 = Node 22，ABI 137 = Node 24）。打包时依赖在构建机上安装，你机器上的 Node 版本不同时就必然失败。

这不是你的问题——发布包本就不该依赖你机器的 Node 版本。

而且 `better-sqlite3` 官方预编译包**没有 Node 24 版本**，所以你无法靠 `npm rebuild` 自愈（那需要 Visual Studio Build Tools）。

### 修复

**发布包现在自带 Node 运行时。**

- 启动时用包内的 Node，**不受你系统里装的是哪个版本影响**
- **你不需要安装 Node.js**
- 启动前有自检：万一随包依赖被换过，会给你一句看得懂的提示，而不是一段堆栈

### 升级

直接运行新版安装包覆盖安装即可。数据在 `data\` 目录，不在覆盖范围内，卸载也保留。

如果 v0.1.0 装完初始化失败（数据库没建成），新版首次启动会自动重建并应用全部迁移。

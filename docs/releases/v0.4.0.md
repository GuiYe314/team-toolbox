# team-toolbox v0.4.0

本版汇总 TASK-037、TASK-039～042。发布与验证结果以 [PROJECT_STATUS](../PROJECT_STATUS.md) 为准。

- **内置视频下载组件**：Yoinks 页面直接使用随包 yt-dlp 2026.10.26 和 ffmpeg/ffprobe 6.1.1，支持分析、视频下载、MP3 提取及取消。无需另装 Yoinks，设置可恢复内置组件或指定已有版本。
- **实时网速**：选择 Windows 服务器网卡，查看上传/下载速度、Mbps、60 秒趋势及本页累计、平均和峰值，支持暂停、清空和后台释放。
- **Unity 文件管理**：安卓调试中浏览所选应用的标准外部 persistentDataPath，预览、下载、添加文件，确认后替换已有文件。
- **多 APK 安装**：单台或多台手机安装多个完整 APK；每台顺序、最多两台并行，逐项显示结果并仅重试失败组合。
- **查看 APK 包名**：选择 APK 后读取并复制包名，无需手机、ADB 或 Android SDK，不会安装或运行 APK。

提供 Windows x64 安装包、便携 ZIP、SHA256 清单和自动更新 manifest.json；内置 Node 22.22.2，组件许可及来源随包分发。独立设备调试版仍在 codex/device-debugger 分支发布，不能与本产品互换安装包。

升级前备份完整 data/ 目录；已有 v0.3.1 可在设置中检查项目 GitHub 更新，安装期间服务会重启。也可关闭软件后安装新版，或将 data/ 复制到全新解压目录。不要把两种产品的程序目录混用。

下载取决于站点、地区和网络，不读取浏览器 Cookie，也不绕过登录或付费限制。实时网速显示服务器网卡流量。Unity 文件操作受 Android 权限及 App 并发写入影响，替换前建议关闭 App 并下载原文件备份；真机兼容性需单独验证。软件继续定位受控本机/局域网使用。

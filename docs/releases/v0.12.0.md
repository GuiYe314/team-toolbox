# team-toolbox v0.12.0

工具分组、快速计算与知识库属性采用 PrimeVue 控件，保留原有液态玻璃明暗主题；Motion for Vue 提供短促的页面、卡片入场和工具标签指示条。

- 工具卡片可从清晰的下拉菜单切换分组；分组开关、管理输入及按钮使用统一控件，弹窗支持焦点限制、Esc关闭和焦点返回。
- 快速计算的输入、单位及精度选择沿用原计算API和方案保存；知识库资料库选择、多选标签与关联支持搜索，取消切换保留原有属性，原数据类型和只读状态继续有效。
- 动效约150毫秒、小位移，无弹跳或退出等待；拖动、后台、减少动态/透明度及离页时停止并还原最终状态。切换工具仍立即卸载原页面。
- 固定 PrimeVue 4.5.5、motion-v 2.12.0 的 MIT 版本，依赖本地分发并保留许可，不增加在线主题、字体请求或数据库迁移。

发行资产为 Windows x64 安装器、便携 ZIP、SHA256 清单和自动更新 manifest.json。可通过“检查更新”获取本版，手动更新请按原用户指南保留 data。系统仍面向受控本机/局域网；独立设备调试版沿用原发行。

使用见[用户指南](../USER_GUIDE.md)，开发与实际验证证据仅记录在[项目状态](../PROJECT_STATUS.md)。

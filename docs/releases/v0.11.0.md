# team-toolbox v0.11.0：知识工作台、SOP与快速计算

知识库新增借鉴 Obsidian 与 Notion 的知识工作台，把笔记关联、资料视图、日常记录和流程放到同一入口。保留原知识库、资源库、视频下载、相册、Unity日志和安卓调试。

- **笔记关联与编辑**：双向链接、反链、未链接提及、大纲、标题/段落嵌入、块编辑/拖排/斜杠、折叠与提示块、同步块及全局/一跳图谱。
- **资料库**：类型化属性、关联和数字汇总；表格、看板、画廊、月历、时间线共用数据，视图筛选/排序/分组可保存，状态看板支持拖放。
- **模板和布局**：页面/资料库模板、每日笔记、多标签分屏、服务端书签与工作区、可保存的笔记/文字知识画布。
- **内容管理**：评论、最近20次标题/正文历史、预览与确认恢复；公开HTTPS网页剪藏预览、Markdown文件夹导入与正文ZIP导出。
- **SOP与动作**：模板每次执行生成独立快照，逐项勾选、备注、续做及历史；结构化按钮和工作台事件可新建模板笔记、设定属性或开始SOP，失败事务回滚。
- **快速计算**：按基准及上下比例生成两组结果，数量/小数位可选，精确十进制、复制、方案保存/搜索/载入/删除。
- **界面**：液态玻璃明暗主题、短暂点击水波纹、安卓调试六个右侧面板独立收放；辅助偏好和清晰下拉菜单保留。

Windows x64提供安装器、便携ZIP、SHA256和自动更新manifest.json，内置Node 22.22.2及已有媒体/OCR/投屏组件。使用入口在“知识库 → 知识工作台 / SOP清单”和“工具箱 → 快速计算”。

升级前先导出全量备份，停止服务后安装或使用设置中的项目GitHub更新源。本版新增SQLite迁移009～011；旧数据自动追加表，新备份包括计算方案、SOP、工作台和历史，原图片/资源仍由全量ZIP保存。回退需使用旧程序及升级前完整数据，不保证旧版读取新结构。独立设备调试版沿用原发行。

高级wiki链接与嵌入在工作台阅读；Markdown导出只含正文层级，完整迁移请用全量备份。剪藏不支持登录页面、内网或所有依赖脚本的网站。工作区与显示名共用服务端数据，当前仍无账号、权限或实时共同编辑，适用于受控本机/局域网。已有手机扫码/投屏兼容范围不因本版扩大。

操作见[用户指南](https://github.com/GuiYe314/team-toolbox/blob/v0.11.0/docs/USER_GUIDE.md#14-知识工作台)，限制见[功能契约](https://github.com/GuiYe314/team-toolbox/blob/v0.11.0/docs/KNOWLEDGE_WORKBENCH.md)，实际验证及发行状态只记录在[项目状态](https://github.com/GuiYe314/team-toolbox/blob/main/docs/PROJECT_STATUS.md)。

# team-toolbox v0.7.0

手机扫码即可把多选照片和视频上传到电脑的工具箱资源库。本版同时包含四款水墨小猫图标选择，以及 v0.6.1 的文件夹修复和视频链接解析更新。实际验收与发布状态见 [PROJECT_STATUS](https://github.com/GuiYe314/team-toolbox/blob/main/docs/PROJECT_STATUS.md)。

- **手机相册上传**：在“工具箱 → 手机相册上传”或资源管理页选择保存文件夹、生成二维码。手机在同一局域网扫码，多选照片/视频，逐项显示进度和保存结果；可停止和重试未完成项，电脑同步显示接收结果。
- **资源保留**：按手机浏览器提供的字节保存，不额外压缩或转码；同名文件新建独立草稿，已有资源不受影响。照片沿用资源库预览和原件下载；HEIC/MOV等格式可能无法预览，原件仍可下载。
- **短期接收**：二维码30分钟有效，每批200项、单文件1GiB、会话8GiB；电脑停止或离开接收页会撤销接收，成功文件仍保留。手机后台/锁屏会停止当前队列，返回后手动重试；刷新页面需重新选文件。
- **应用图标可选**：设置中可选择墨猫剪影、雪猫烟墨、圆墨小猫、窗边小猫或默认06字标，同步侧栏和浏览器标签页，提供ICO下载及恢复默认。

提供 Windows x64 安装器、便携 ZIP、SHA256 校验清单与热更新 manifest.json，内置 Node 22.22.2 和原有下载组件/许可。没有数据库结构变化；仅更新完整工具箱，独立设备调试工具保持原发行版本。

旧版完整工具箱可在“设置”中检查项目 GitHub 更新，或关闭服务、备份 data/ 后使用本版安装器/便携包升级。需以Lan模式运行并选择手机可访问的私网地址；仅用于可信局域网。实际手机扫码、Android/iOS系统相册和另一物理客户端未验收，不保证每种手机格式均可预览。

# v0.3.1：GitHub 热更新与后台升级修复

本版默认使用本项目 GitHub Releases，支持粘贴仓库地址、关闭及恢复更新，修复代理检查超时和后台替换、重启失败。功能范围为 F-OPS-003 / TASK-036；发布状态与验证记录见 [项目状态](../PROJECT_STATUS.md)。

## 主要变化

- **项目 GitHub 更新源**：首次无配置默认使用本项目最新正式 Release。仓库 HTTPS 地址、以 `.git` 结尾的地址及 Releases 首页自动转换为发布资产目录；已有自定义源及明确关闭状态继续保留。
- **设置页**：新增“使用项目 GitHub”和“关闭更新”，支持回车保存；换源后清除旧源检查结果及安装按钮，错误原因直接显示。
- **代理修复**：更新清单和 ZIP 优先使用 HTTP(S)_PROXY / ALL_PROXY，其次 Windows 当前用户手动 HTTP/HTTPS 代理，并遵守 NO_PROXY / Windows 绕过列表。回环直连，代理只用于更新器；不执行 PAC 或 SOCKS，不保存代理凭据。
- **下载保护**：清单限制 1 MiB，完整响应保留超时；ZIP 继续流式校验 SHA256、失败清理、运行时自检、备份、确认安装、重启及失败回滚。
- **后台升级执行修复**：替换脚本全部使用 ASCII，中文路径通过 Unicode 环境传入；禁用延迟展开、移除后台管道等待，重启显式使用 CMD /c /nopause。独立副本已验证成功替换和启动失败回滚，保留数据及配置。
- **保留原有工具**：安卓无线调试、多设备 APK 安装、手机屏幕和日志、地球光照、开源工具与受控局域网访问。

| 文件 | 用途 |
|---|---|
| `team-toolbox-Setup-0.3.1.exe` | Windows x64 安装包 |
| `team-toolbox-0.3.1.zip` | 便携包，解压后双击 `启动.cmd` |
| `team-toolbox-0.3.1-SHA256.txt` | 安装包及便携包 SHA256 与大小 |
| `manifest.json` | 自动更新清单，与便携包同时发布 |

包内自带 Node v22.22.2 和生产依赖，无需另装 Node。没有新增 SQLite 迁移。

已有版本可在“设置 → 更新源地址”填写 `https://github.com/GuiYe314/team-toolbox/releases/latest/download`，主动检查后确认安装。v0.3.1 也支持直接填写 `https://github.com/GuiYe314/team-toolbox.git`。更新会备份并重启服务，页面短暂断开后刷新；发布者只推送源码时不会产生可安装更新。

**旧版用户建议先手动安装本版**：原 v0.3.0 更新器在独立副本中已发现后台替换/重启失败；需要代理的旧版还可能无法下载。本版修复这些问题，但本版成功/回滚验收使用的是新版更新器，不能代表旧版自动升级已通过。手动升级前创建完整备份并关闭旧服务，保留原 `data/`；设备及上游工具仍需在服务器电脑配置。

# team-toolbox v0.8.2

手机扫码上传相册与视频下载两条线合并后的完整版本。视频下载改为后台任务队列：不再限制体积与时长、可多任务并发、断点续传、下完自动放进下载目录，还能不落盘边下边看；新增 91porna 站点解析。实际验收与发布状态见 [PROJECT_STATUS](https://github.com/GuiYe314/team-toolbox/blob/main/docs/PROJECT_STATUS.md)。

- **视频下载改为任务队列**：点「下载」立即返回任务号，右侧按「排队中 / 下载中 / 已完成 / 失败 / 已暂停」列出全部任务，并发 3、排队不限。关掉页面任务继续跑，回来仍能看到进度与结果；每项可取消、重试、打开文件夹、另存、移除。
- **去掉单文件 1 GiB 与 15 分钟限制**：改为「五分钟没有任何字节进展才暂停」的看门狗。大文件不再被体积或总时长误杀，卡死任务也不会永久占住并发位。
- **断点续传**：按「链接 + 清晰度」生成稳定缓存目录并显式续传，取消、失败、断网都保留分片，重试同一链接接着下；任务区底部显示缓存占用，可一键清理（正在跑的任务目录不动）。
- **自动保存到下载目录**：设置里可选保存目录，留空用系统「下载」文件夹；完成后按视频标题改名移入，重名自动加 `(2)`、`(3)`，目录不存在自动创建。移动失败时保留临时文件并提示「保存到电脑」。
- **「先看看」实时预览**：解析后点「先看看」，后端用内置 ffmpeg 读远端流实时转封装成 fragmented MP4，浏览器几秒出画面，不占下载并发位、不写缓存目录；面板里可直接切到下载该清晰度，关闭页面立即停止拉流。
- **新增 91porna 解析方案**：这类页面 HTML 里没有 `<video>` 也没有可提取的清单，内置方案按页面脚本的做法调 `POST /api/videos/<video_key>/playback` 换 HLS 地址，AES-128 加密流由 yt-dlp 自动取密钥解密合并。
- **手机相册上传**：在「工具箱 → 手机相册上传」或资源管理页选择保存文件夹、生成二维码。手机同一局域网扫码，多选照片/视频，逐项显示进度与保存结果，可停止并重试未完成项。二维码 30 分钟有效，每批 200 项、单文件 1 GiB、会话 8 GiB；文件按手机提供的字节保存，不额外压缩或转码。
- **应用图标可选**：设置中可选择墨猫剪影、雪猫烟墨、圆墨小猫、窗边小猫或默认 06 字标，同步侧栏与浏览器标签页，提供 ICO 下载及恢复默认。

提供 Windows x64 安装器、便携 ZIP、SHA256 校验清单与热更新 manifest.json，内置 Node 22.22.2 和原有下载组件及许可。没有数据库结构变化，`data/` 目录不受安装包覆盖。

旧版完整工具箱可在「设置」中检查项目 GitHub 更新，或关闭服务、备份 `data/` 后使用本版安装器 / 便携包升级。视频下载的实时预览不支持随意拖动进度条，HEVC / AV1 编码部分浏览器无法直接解码（界面会提示改用下载后本地播放）；91porna 方案只能拿到站点给免费用户的档位，4K / 1080 需要站点会员，接口层不下发地址。手机相册需以 Lan 模式运行并选择手机可访问的私网地址，仅用于可信局域网；实际手机扫码、Android/iOS 系统相册和另一物理客户端未验收，不保证每种手机格式均可预览。

# v0.15.0

发布日期：2026-11-20

## 项目待办

- 知识库新增“项目待办”，用“项目 → 待办”两层整理问题。
- 支持项目与待办的新增、编辑、确认删除，以及空项目删除。
- 勾选问题后立即归档，支持在“已归档”视图取消勾选恢复。
- 提供进行中、已归档和全部三种视图。
- 保存冲突、失败重试、离页和刷新都会保护未保存草稿。
- 项目、问题和归档时间进入 JSON、压缩 JSON 与全量 ZIP 备份。
- 迁移 012 兼容已有知识库和旧备份。

## 界面

- 修复暗色主题主按钮背景，提升“新增项目”等按钮的文字对比度。

## 发布资产

- Windows x64 安装器
- Windows x64 便携 ZIP
- SHA256 校验清单
- 自动更新 `manifest.json`

本版本面向受控本机或局域网环境使用。

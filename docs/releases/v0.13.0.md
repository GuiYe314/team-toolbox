# team-toolbox v0.13.0

新增网页文件夹共享和真正的 FTP／FTPS／SFTP 客户端，暗色界面改为黑灰纯色。

- **文件夹共享**：在工具箱选择电脑目录，确认只读或可上传权限及共享期限，手机或其他电脑可通过链接、二维码浏览、搜索和下载。可上传共享支持批量上传、新建目录、逐项进度、取消和重试；同名文件另存，保留原件。
- **共享管理**：离开管理页后共享继续；停止、到期或正常退出服务时撤销访问并清理未完成传输。文件直接读写选定目录，不进入资源库或知识库备份。
- **FTP 文件客户端**：提供协议、服务器、端口与账号连接栏，本地待传／远端目录双栏和传输队列；支持多文件顺序上传、原生下载、目录搜索、新建目录、重命名，以及确认删除文件或空目录。
- **连接与覆盖**：显式 FTPS 验证服务器证书，SFTP 须核对 SHA-256 主机指纹后登录；密码和会话不保存。默认拒绝同名覆盖，覆盖需明确确认；网络断开无法确认远端暂存清理时会提示核对，不把传输字节等同于最终保存成功。
- **黑灰暗色主题**：页面、侧栏、卡片、输入、下拉菜单、日志和弹窗统一为中性黑灰纯色，去掉暗色彩色光晕和表面渐变，保留清晰的选中、焦点及状态颜色。浅色沿用原有玻璃材质。

文件共享适合可信局域网，须使用能访问工具箱电脑的局域网地址；真实手机扫码和系统文件选择能力取决于设备。FTP 为明文协议，优先使用 FTPS 或 SFTP；本版不提供私钥登录、断点续传、自动重连或递归删除，不支持多个客户端同时修改同一目标。SFTP 服务器不支持原子替换时保留原件并提示换名。

发行资产为 Windows x64 安装器、便携 ZIP、SHA256 清单和自动更新 manifest.json。可通过“检查更新”获取本版，手动更新按用户指南保留 data；无数据库结构迁移，独立设备调试版沿用原发行。系统仍面向受控本机／局域网。

使用见[用户指南](../USER_GUIDE.md)，实际验证和发布证据仅记录在[项目状态](../PROJECT_STATUS.md)。

# v0.2.0：安卓无线调试与设备日志

本版增加安卓设备连接、应用日志和网页屏幕预览，并提供 Unity 局域网设备日志入口。原有知识库、资源管理、备份与自动更新继续沿用。发布与验收状态统一见 [项目状态](../PROJECT_STATUS.md)。

## 安卓无线调试

- 在“工具箱 → 安卓无线调试”中使用。点击“ADB 设置”输入 Platform-Tools 或 SDK 文件夹，自动搜索 `adb.exe`；多个候选由用户选择。点击“帮助”查看详细步骤。
- 手机打开 Android 11 及以上的无线调试，可扫描两分钟有效的配对二维码，或用六位码配对；支持 mDNS 搜索、手动地址连接与单台无线设备断开。
- 双栏分别展示连接与设备列表，以及常用命令、手机屏幕和设备日志；明暗主题下的下拉菜单调整为清晰的不透明底色。
- 内置常用命令精简为锁定程序、解锁程序（恢复桌面）、IP、设备信息、内存和 CPU；支持添加、编辑、删除自己的命令，执行前核对设备与参数并确认。
- 锁定/恢复桌面读取当前 Android 用户的 HOME 应用，主动选择并确认后设置默认桌面。仅支持有 HOME 入口的应用，不提供系统级禁退锁定。
- 日志可选择设备全部日志或指定 App，查看包名、运行状态和 PID，跟随主进程与子进程；支持级别及关键词筛选。
- 手机屏幕支持单次读取，以及 1、2、5 秒间隔连续刷新，可停止、清空、放大。实际速度取决于设备和网络；截图留在内存，不自动保存。

ADB 由运行工具箱的电脑执行，安卓工具页面仅允许从服务器本机的 `localhost` 或 `127.0.0.1` 访问。平台工具需要自行安装，手机需与电脑网络互通。完整步骤见 [用户指南](../USER_GUIDE.md#6-安卓无线调试)。

## Unity 局域网设备日志

在“工具箱 → Unity 设备日志”搜索同网段 Android/iPad 的专用日志服务，按固定编号选择设备，查看历史文件、完整堆栈，筛选或复制内容，下载全文和 ZIP，支持自动刷新。无需 ADB 或扫码。

设备端必须包含新版 `Assets/Test/Log` 模块并完整重打 APK/iOS 包，单独更新网页或热更新不够。工具页面仅限服务器本机，设备需保持前台并允许局域网访问。详细步骤见 [用户指南](../USER_GUIDE.md#7-unity-局域网设备日志)。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `team-toolbox-Setup-0.2.0.exe` | Windows x64 安装包，含运行时与生产依赖 |
| `team-toolbox-0.2.0.zip` | Windows x64 便携包，解压后双击 `启动.cmd` |
| `team-toolbox-0.2.0-SHA256.txt` | 下载文件的 SHA256 与大小 |
| `manifest.json` | 自动更新清单，与便携包同时放在更新源 |

升级前在原版中创建完整数据备份，并关闭旧服务。v0.1.2 可在“设置”填写更新源 `https://github.com/GuiYe314/team-toolbox/releases/latest/download`，检查后下载并安装；出网受限时也可使用保存了清单和 ZIP 的内网目录。更早版本需手动下载安装包或便携包。手动替换程序时保留原 `data/`。

包内自带 Node 和生产依赖，无需安装系统 Node 或运行 `npm install`。源码开发版新增根目录 `stop.bat`，用于关闭同目录 `start.bat` 启动的服务；发布包仍使用 `启动.cmd` / `停止.cmd`。

## 使用限制

真实 Android/iPad 的连接、扫码、HOME 切换、应用日志和屏幕刷新仍需在对应硬件验证；离线与浏览器替身验证的范围见项目状态。App 显示运行中表示检测到匹配进程，不等于前台或健康状态；受保护画面可能黑屏。

项目继续面向受控本机/内网，尚无账号与权限系统。视频缩略图仍需服务器安装 `ffmpeg`。

# team-toolbox v0.6.1

本版为修复版，并包含 v0.6.0 之后尚未发布的视频下载统一链接解析改动。实际发布与验收证据见 [PROJECT_STATUS](https://github.com/GuiYe314/team-toolbox/blob/main/docs/PROJECT_STATUS.md)。

## 修复

- **新建文件夹不再报 `Too few parameter values were provided`**：资源管理页点「新建文件夹」或文件夹行的「+」，弹窗标题曾错成「新建子文件夹」，确定后报英文 SQL 驱动错误、创建失败。
  - 原因是两处事件绑定把对象当成了父文件夹 ID：工具栏按钮写成 `@click="createFolder"`，Vue 会把点击事件对象作为第一个参数传入；文件夹树的 `create-child` emit 的是整个节点对象，而绑定直接写成了 `@create-child="createFolder"`。对象经 JSON 变成 `{}` 后进入 SQL 绑定，`better-sqlite3` 按命名参数取键失败。
  - 现在按钮传 `null`、树传 `node.id`，`createFolder` 内部再统一归一化为正整数 ID；后端 `asset-store.js` 增加入口校验，`createFolder` / `moveFolder` / `moveAssets` 遇到对象或非法 ID 时返回 **400「父文件夹 ID 无效」**，不再把驱动层英文错误透传给用户。

## 视频下载：统一链接解析

- 所有链接走同一个解析入口，按优先级依次尝试，某个方案失败自动交给下一个，成功即停；页面上会显示每个方案的「成功 / 失败 / 跳过 / 耗时」以及最终由哪个方案解析成功。
- 内置三个方案：直链媒体（HEAD 校验后免网页解析）、yt-dlp 通用解析（原有清晰度与 MP3 逻辑不变）、yt-dlp 通用页面（兜底）。类型不匹配的方案标为跳过，不发网络请求。
- 可扩展：安装目录 `data/video-resolvers.json` 可配置最多 32 个自定义 HTTP 解析服务（`domains` / `priority` / `enabled`，改完无需重启），或用 `registerResolver()` 注册代码级方案。详见 [video-resolvers](../video-resolvers.md)。
- 工具 id、路由 `/tools/yoinks` 与卡片数量均未变，个人卡片排序与全部既有浏览器验收断言继续有效。

## 资产

提供 Windows x64 安装器、便携 ZIP、SHA256 校验清单和自动更新 `manifest.json`；内置 Node 22.22.2 运行时、固定下载组件及全部原有许可。二进制不进入源码提交。

## 升级方式

安装前关闭服务并备份整个 `data/`；已有主工具箱可在「设置」中检查 GitHub 更新，或下载本版安装器/便携包覆盖升级。不要把独立设备调试版与完整工具箱的程序目录互换。

# team-toolbox v0.6.0

本版包含 TASK-045 工具卡片排序与下拉菜单可读性调整。实际发布与验收证据见 [PROJECT_STATUS](https://github.com/GuiYe314/team-toolbox/blob/main/docs/PROJECT_STATUS.md)。

- **工具卡片可拖拽排序**：在“工具箱”拖动卡片，放到目标左半区排在前面、右半区排在后面，可直接移动到首尾；高亮边缘提示放置位置。
- **自动保存个人顺序**：刷新后保留，首页已有工具入口跟随相对顺序；支持“恢复默认顺序”。浏览器无法保存时提供明确提示及重试。
- **下拉菜单更清晰**：普通下拉菜单采用适配明暗主题的不透明底色，提升未选项与选中项的文字对比度，包括知识库的父页面选择。

排序保存在当前浏览器，浏览器、电脑及访问地址不同会分别保存，不写入团队数据库或备份。已有工具和数据结构沿用原版；本次仅更新完整工具箱，独立设备调试工具沿用其现有版本。

提供 Windows x64 安装器、便携 ZIP、SHA256 校验清单和自动更新 manifest.json；内置 Node 22.22.2、固定下载组件及全部原有许可。安装前关闭服务并备份整个 data/；已有主工具箱可在设置中检查 GitHub 更新，或下载本版安装器/便携包升级。不要把独立设备调试版与完整工具箱的程序目录互换。

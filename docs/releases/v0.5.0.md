# team-toolbox v0.5.0

本版包含 TASK-043 端口查看与 TASK-044 石墨字标。实际发布和验收证据见 [PROJECT_STATUS](../PROJECT_STATUS.md)。

- 新增**端口查看**：查看运行工具箱的 Windows 电脑上的 TCP/UDP 端点、监听/连接状态、地址、PID 与进程名，支持精确端口/关键词筛选、分页、复制、5秒刷新及后台暂停。
- 采用 **06「石墨字标」TT**：同步网页侧栏、标签页/触摸图标、Windows 安装器与开始菜单/可选桌面快捷方式；保留全套26个多尺寸 ICO 和可编辑 SVG。
- 新增“**创建快捷方式.cmd**”：在程序目录的“快捷方式/”生成带图标的启动与关闭入口，可复制到桌面；移动程序目录后重新生成。

提供 Windows x64 安装器、便携ZIP、SHA256及自动更新manifest.json；内置Node22.22.2和原有固定下载组件及完整许可。安卓调试、Unity日志、多APK安装、persistentDataPath文件管理、包名查看等原有功能保留，不改变数据结构。

安装前关闭服务并备份整个data/；已有主工具箱可在设置中检查GitHub更新，或安装本产品新版。设备调试工具使用独立device-debugger资产，不能互换程序目录。

端口信息是服务器的瞬时只读快照，不会扫描远端或结束进程；系统权限可能使进程名缺失，PID可能复用，超时/截断会明确提示。软件仍面向受控本机/局域网；真实手机及另一物理客户端的兼容性不属于本次图标和端口验收。

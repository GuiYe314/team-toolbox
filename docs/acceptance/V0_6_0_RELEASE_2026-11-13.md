拖放脚本最初在刚进入子元素后直接释放，没有产生最后一次原生 dragover；补齐鼠标移动后实际前后放置通过，取消由浏览器原生取消 API 验证。截图已目视检查明暗主题；父页面 option 截图使用 size=3 展开真实列表样式，不将其称为系统弹出菜单截图。

安装验收最初因 PowerShell 输出编码使中文路径比较失败；修正 UTF-8 读取，使用本轮安装器恢复并卸载该临时安装后完整复验。当前用户临时卸载身份已清理，原有机器级安装注册保持原值。旧版升级保留文档、data、更新源与全部下载组件。

公开 CC0 源先出现分析或下载失败，最终有限重试后由随包 yt-dlp 和 FFmpeg 实际完成 MP3，结果领取及回收通过。生产脚本因真实端口超时未整体结束；后续通用网页已通过，首次续接脚本遗漏 lanAddress 变量，修正为独立 Local/Lan 检查后 11/11，不重复已通过的下载与页面测试。端口超时后的一次停止遇到已退出子进程而返回非零，后续独立启停检查通过；这些早期失败日志均保留，未改产品代码来掩盖结果。

本轮为界面改动，不改变既有端口采集器及其限时策略。端口环境失败作为发布验收限制保留；相关后端及隔离浏览器回归通过。没有真实手机安装/扫码、X 网站视频下载或另一物理客户端验收。

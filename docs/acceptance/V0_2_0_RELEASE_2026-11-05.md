本次打包使用 `scripts/build_release.ps1 -Version 0.2.0`，内置官方 Node **v22.22.2 / ABI 127**，依赖在暂存目录由同源 Node/npm 安装。Node 下载文件与官方 `SHASUMS256.txt` 一致；Inno Setup 6.7.4 安装文件 Authenticode 签名有效。

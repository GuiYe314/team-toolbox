# team-toolbox（团队工具箱）

面向内部小团队的网页版工具集合，提供 Markdown 知识库、资源管理与实用工具。知识库支持文档编辑、分类、标签、搜索及服务端持久化；工具箱提供比例锁定、安卓无线调试和 Unity 局域网设备日志等入口。

> **使用边界**：第一版仅面向受控的本机/内网环境，未内置认证与权限控制，**不得暴露到公网**。详见 [ARCHITECTURE](docs/ARCHITECTURE.md) 第 7 节“内部访问边界”。

- 仓库：https://github.com/GuiYe314/team-toolbox（公开）
  > 代码公开 **不等于** 服务可以公开部署：本系统第一版无认证，仍只允许跑在受控本机/内网。
- 文档基线日期：2026-10-16
- 当前状态：**进度唯一来源：[docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md)**。

## 范围速览

- **MVP（v0.1）**：知识库（文档 CRUD、分类、标签、搜索、服务端持久化、首页最近更新）+ 工具导航框架 + 受控内网部署边界 + 备份恢复手段。
- **延期（不计入 MVP 完成门槛）**：实时共同编辑（F-COL-001）、账号与权限（F-SEC-001）。

数据库确定为 **SQLite**，具体存储与实施约定见 [架构说明](docs/ARCHITECTURE.md) 第 10 节。

## Yoinks、FreeLLMAPI 与 ArtCraft

首页和工具箱提供三个中文入口，各页右上角有设置和帮助：

- **Yoinks 视频下载**：粘贴视频网页链接、分析清晰度、下载视频或 MP3、取消并保存结果。复用 Yoinks 的 yt-dlp 下载核心，需准备 yt-dlp；高清合并与 MP3 需 ffmpeg，可检测 PATH / Yoinks 组件或手动填写路径。
- **FreeLLMAPI 模型对话**：连接本机 FreeLLMAPI，读取可用模型并进行可停止的流式聊天。需先运行上游服务并填写统一 API Key；Key 只保留在工具箱后端内存，重启后重新设置，不进入团队数据或备份。
- **ArtCraft 创作台**：整理、编辑和复制提示词，配置本机 ArtCraft.exe 并确认启动。原生编辑画布在 ArtCraft 自己的桌面窗口打开，模型生成与账号仍由它负责。

三个接入支持服务器本机及 Lan 模式下的同网段访问；程序和模型网关仍在工具箱服务器运行。工具箱不自动安装上游程序、不自带模型或供应商额度。操作步骤见 [用户指南第 9 节](docs/USER_GUIDE.md#9-开源工具接入)，接入方式、依赖和许可见 [开源接入说明](docs/OPEN_SOURCE_INTEGRATIONS.md)。

## 地球光照

从“工具箱 → 地球光照”或首页同名卡片进入，查看写实三维地球、当前白昼/黑夜、昼夜分界和太阳直射点。地球采用 4K 地表和夜景贴图，叠加云层、夜间城市灯光及蓝色大气边缘；金色射线表示阳光到达方向，右侧显示直射经纬度、本机时间与 UTC 时间。

太阳采用暖色光球、表面颗粒和柔和日冕。青色实线标出赤道（0°），紫色虚线标出北回归线（23.44°N）与南回归线（23.44°S），附中文标注；纬线随地球旋转，背面标注自动隐藏，简化视图也保留三条纬线。

每 30 秒自动更新，也可点击“立即刷新”。拖动地球、使用方向键或左右按钮旋转，用滚轮、双指、加减按钮或键盘 ＋/－ 缩放；点击“回到光照视角”或按 Home 恢复视角与缩放。Globe.gl / Three.js 及全部贴图随项目本地分发，无需定位、API Key 或外部地图服务；三维显示或素材加载失败时保留简化示意并可重试。云层和城市灯光是静态素材，太阳位置按本机时钟近似计算。素材作者、许可及处理说明见 [地球素材](frontend/src/assets/earth/README.md)，操作见 [用户指南](docs/USER_GUIDE.md#8-地球光照)。

## 安卓无线调试

从“工具箱 → 安卓无线调试”进入，点击“帮助”查看连接步骤与故障处理，点击“ADB 设置”弹窗搜索和选择 ADB；普通设置页也提供同一弹窗入口。界面左侧集中扫码、手动连接、无线服务搜索及设备列表，右侧为常用命令、APK 安装、手机屏幕和实时设备日志，两栏可以分别滚动。

在运行工具箱的电脑安装 [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)，手机与电脑连接同一局域网，并在 Android 11 及以上的开发者选项中打开无线调试。此工具支持通过启动器显示的局域网地址访问；ADB 操作和配置路径均在运行工具箱的服务器电脑。

首次在“ADB 设置”弹窗填写已解压的 Platform-Tools 文件夹（也可填写上级 SDK 文件夹），自动搜索 `adb.exe`；找到多个版本时选择一个。关闭弹窗后点击“生成配对二维码”，在手机“无线调试 → 使用二维码配对设备”中扫码，自动配对、连接并刷新设备。二维码两分钟有效；也支持六位码配对、IPv4 地址连接和单台无线设备断开。

“常用 ADB 命令”内置六项：锁定程序、解锁程序（恢复桌面）、获取 IP、设备信息、手机内存使用和 CPU 使用。锁定与解锁从手机读取当前用户和 HOME 应用，搜索并选择程序或桌面后，核对目标再确认设置。该命令改变默认桌面，仅支持有 HOME 入口的应用；按手机主页键进入，不提供系统级禁退锁定。IP 查询全部 IPv4 接口，内存和 CPU 返回系统查询快照。详细步骤见 [用户指南](docs/USER_GUIDE.md#6-安卓无线调试)。

点击命令区“添加命令”可设置名称、分类、参数和说明，保存后在列表选择使用，支持编辑和确认删除。例如 `shell dumpsys meminfo com.example.app`，不用填写 `adb` 或设备序列号。自定义命令每次执行前展示目标与完整参数并要求确认，配置在服务器本机保存，重启后保留；具体参数范围见帮助。

“APK 传送安装”可选择电脑上的单个 APK 和在线设备，核对文件名、大小及目标后确认传送安装。勾选“多设备安装”可多选或全选在线手机（每批最多 20 台），同一 APK 只上传一次，再逐台安装并实时显示各台结果；单台失败或超时继续下一台，可只选择失败设备重新确认安装。支持取消，已完成的安装不回滚；覆盖同包名应用并保留数据，不自动卸载或打开应用。支持最多 1 GiB 的完整 APK，AAB/APKS 不能直接安装，具体步骤及取消限制见帮助。

“手机屏幕”可选择在线设备，单次刷新或按 1、2、5 秒间隔连续读取截图；每次读取完成后再等待所选间隔。支持停止并保留最后画面、清空及放大查看。切换设备、修改配置或离开页面会停止并清空，页面进入后台会停止读取。图片只在内存中，实际刷新速度取决于设备与网络，受保护内容可能黑屏。

“设备日志”可对所选在线设备开始、停止实时 Logcat，支持最低级别、关键词、自动滚动和清空显示。日志仅保留在有界内存中，切换设备、离开页面或修改配置会结束采集；下拉菜单使用适配明暗主题的不透明底色和清晰文字。

需要查看某个 App 时，把“日志范围”切换为“指定应用”，按包名搜索并选择，查看是否运行、进程号和最后检查时间。开始采集后仅返回匹配主进程与子进程的日志，应用退出时等待，重启后定期跟随新进程；运行中表示进程存在，不代表在前台。捕获范围见用户指南。

## Unity 局域网设备日志

从“工具箱 → Unity 设备日志”进入，点击“搜索局域网”，选择 Android 手机或 iPad，即可查看设备保存的启动与热更日志。支持历史文件、等级/关键词筛选、完整堆栈、自动刷新、复制、全文及 ZIP 下载；无需 ADB、扫码或输入访问码。按固定设备编号识别，IP 改变后重新搜索。

设备需运行新版 `Assets/Test/Log` 模块，**必须重新打 APK/iOS 包，仅热更新不能加入新的发现协议**。`StartupLogManager` 默认自动开启局域网读取，应用保持前台，电脑与设备应处于可互通的 IPv4 局域网。工具页面可在同网段浏览器通过工具箱地址打开，搜索仍由服务器电脑执行，默认设备端口 17523。

搜索按网卡掩码生成范围，最多检查 1024 个地址并显示实际覆盖情况；大网段可用“搜索设置与指定 IP”补查。同 Wi-Fi 下的设备隔离、iPad 本地网络权限或防火墙仍可能阻止连接。日志只读，不自动保存到团队数据库或备份。详细操作见 [用户指南](docs/USER_GUIDE.md#7-unity-局域网设备日志)，验证与真机限制见 [项目状态](docs/PROJECT_STATUS.md)。

## Windows 源码版启动与关闭

双击启动默认允许同网段设备访问全部工具（包括 ADB、Unity 日志）。使用启动信息中的 `http://服务器IPv4:5173/`；服务器本机仍可用 localhost。仅本机使用可执行 `start.bat /local`。程序路径、设备搜索和外部应用启动均指运行工具箱的电脑；网络配置及排查见 [局域网访问](docs/USER_GUIDE.md#06-局域网访问)。

- 双击根目录 `start.bat` 启动后端和前端开发服务；两个服务都就绪后，启动 CMD 自动关闭，服务继续在后台运行。
- 启动失败时窗口保留错误摘要，标准输出与错误保存在项目 `logs/` 目录，每次启动保留上一份日志。
- 双击根目录 `stop.bat` 关闭该目录下的后台服务及其子进程，保留数据文件。
- 命令行执行 `stop.bat /nopause` 可跳过结束时的按键等待；服务未运行时也可执行。

关闭脚本按项目路径识别进程。手动在终端使用相对路径启动的服务，可在对应终端按 `Ctrl+C` 关闭。发布包的启动与停止方式见 [用户指南](docs/USER_GUIDE.md)。

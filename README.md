# team-toolbox（团队工具箱）

面向内部小团队的网页版工具集合，提供 Markdown 知识库、资源管理与实用工具。知识库支持文档编辑、分类、标签、搜索及服务端持久化；工具箱提供比例锁定、安卓无线调试和 Unity 局域网设备日志等入口，支持工具分组、跨组拖拽及顶部工具标签。

知识库的“知识工作台”提供双向链接、反向链接、大纲、块编辑与嵌入、关系图谱，以及表格／看板／画廊／日历／时间线资料库。还可使用页面模板、每日笔记、多标签分屏、书签与工作区、知识画布、同步块、评论、正文历史、网页剪藏和 Markdown 文件夹迁移。按钮及事件动作可从模板新建笔记、设置属性或开始 SOP。原 Markdown 编辑器与文档数据共用，操作见[知识工作台指南](docs/USER_GUIDE.md#14-知识工作台)。

“SOP清单”将流程保存为模板，每次执行生成独立记录，支持逐项勾选、备注、继续执行和历史查询；修改模板不影响已有执行记录。“工具箱 → 快速计算”按基准值和上下比例生成两组结果，可选择数量、精度，并命名保存计算方案。笔记、资料库、工作区、SOP与计算方案均保存在工具箱电脑，备份菜单可一并导出；[SOP与快速计算步骤](docs/USER_GUIDE.md#15-sop检查清单)。

“知识库 → 项目待办”按“项目 → 待办”两层整理问题，条目显示“项目 — 问题”。勾选完成后自动归档，可在“已归档”取消勾选恢复，也可查看全部；项目与待办支持编辑及确认删除，数据保存在工具箱电脑并随知识库备份导出。操作见[项目待办指南](docs/USER_GUIDE.md#19-项目待办)。

在“工具箱 → 管理分组”新增、改名、调整顺序或删除分组，每组可启用/停用及展开/收起；卡片可选择所属分组，也可直接拖到其他组。顶部固定“工具箱”标签，打开工具自动新增对应标签，可切换或关闭。分组和排序在当前浏览器保存，工具标签在当前浏览器标签页刷新后保留。操作见[用户指南](docs/USER_GUIDE.md#27-工具分组与顶部标签)。

“设置 → 应用图标”可在四款黑白水墨玻璃小猫和默认 06 石墨字标间切换，立即同步网页侧栏与浏览器标签页，刷新后保留；也可下载 ICO 用于 Windows 快捷方式。图标选择属于当前浏览器的个人偏好，操作见[用户指南](docs/USER_GUIDE.md#应用图标与-windows-快捷方式)。

界面支持明暗双主题：浅色采用参考苹果液态玻璃的通透环境色、细亮边缘与柔和阴影；暗色采用黑灰纯色背景，以中性灰明度区分侧栏、卡片、输入框和菜单。侧栏底部可切换主题；系统减少动态效果或减少透明度时自动降低视觉效果，下拉菜单及日志区保留清晰底色。

使用 PrimeVue 4.x 控件和 Motion for Vue 动效：工具分组、计算表单和笔记属性支持清晰的单选/多选、搜索及键盘操作，分组管理使用聚焦弹窗和滑动开关。页面与卡片轻微入场，顶部工具标签的指示条跟随选择；后台或减少动态时直接显示最终状态，依赖随工具箱本地分发。

按钮、导航和工具标签采用短暂水波纹反馈，保留原有选中底色；知识库可用“父子页面目录 + 资料类型分类 + 关键词标签”整理，操作与示例见[知识库整理指南](docs/USER_GUIDE.md#建议的个人知识库整理方式)。

> **使用边界**：第一版仅面向受控的本机/内网环境，未内置认证与权限控制，**不得暴露到公网**。详见 [ARCHITECTURE](docs/ARCHITECTURE.md) 第 7 节“内部访问边界”。

## 图片、文档与设备工具

工具箱内提供八个独立入口，支持现有分组和顶部标签：

| 工具 | 功能 |
|---|---|
| 图片批处理 | 多图缩放、裁剪、压缩、旋转、格式转换和文字水印，逐项下载 |
| 图片文字识别 | 本地中英文 OCR，支持停止、编辑、复制和下载文字 |
| PDF 工具 | 合并、提取页面、旋转、水印及 JPG/PNG 转 PDF |
| 视频处理 | 批量压制、CRF/码率、帧率/音频/字幕、Unity预设与自定义模板，保留MP4/MP3/GIF |
| 安卓流畅投屏 | scrcpy 连续视频、鼠标触控、常用按键和英文输入 |
| 白板与流程图 | Excalidraw 画布、源文件/PNG 导出、资源库保存与读取 |
| 手机与电脑双向互传 | 同网段扫码连接、文字和文件直传、接收确认及摘要校验 |
| 开发工具合集 | JSON、编码、时间戳、UUID、哈希、正则、颜色、二维码和文本对比 |

OCR 模型、白板字体和页面依赖本地分发；图片/视频仅在工具箱电脑临时处理，PDF、OCR、开发输入在浏览器处理。安卓流畅投屏需要支持 WebCodecs 的安全上下文，局域网 HTTP 可使用既有截图预览；iOS AirPlay 需另行接入。使用与组件准备见[用户指南](docs/USER_GUIDE.md#13-图片文档与设备工具)，验证和真机范围见[项目状态](docs/PROJECT_STATUS.md)，来源见[开源接入说明](docs/OPEN_SOURCE_INTEGRATIONS.md)。

## 视频下载（Yoinks）

首页和工具箱提供“视频下载”入口，页面右上角有设置和帮助：

- **视频下载（Yoinks）**：工具箱首页与工具箱卡片显示为「视频下载」，粘贴一个链接即可，后端按优先级**自动依次尝试多个解析方案**，能解析就用、不行就换下一个，页面显示每个方案的结果与最终由哪个方案解析成功；支持直链媒体、yt-dlp 通用解析、网页媒体提取、yt-dlp 通用页面四种内置方案，以及通过 `data/video-resolvers.json` 接入最多32个自定义 HTTP 解析服务。随后选择清晰度或 MP3、下载、取消并保存结果。Windows 完整工具箱内置 yt-dlp、ffmpeg/ffprobe，无需另装 Yoinks；组件设置可指定其他版本或恢复内置组件。扩展方式见[统一链接解析文档](docs/video-resolvers.md)，源码首次准备见[用户指南](docs/USER_GUIDE.md#91-yoinks-视频下载)。

视频下载支持服务器本机及 Lan 模式下的同网段访问，下载组件在工具箱服务器运行。FreeLLMAPI 模型对话和 ArtCraft 创作台的网页入口及页面已移除，旧链接会返回工具箱。操作步骤见 [用户指南第 9 节](docs/USER_GUIDE.md#9-开源工具接入)，接入方式、依赖和许可见 [开源接入说明](docs/OPEN_SOURCE_INTEGRATIONS.md)。

## FTP 文件客户端

“工具箱 → FTP 文件客户端”输入协议、主机、端口和账号密码，连接 FTP、显式 FTPS 或 SFTP 服务器。上方连接栏、左右本地待传文件/远端目录、下方传输队列，支持批量顺序上传、原生下载、新建目录、重命名和删除文件或空目录，沿用 PrimeVue 与玻璃明暗主题。

SFTP 先核对服务器指纹，FTPS 验证证书；上传默认不覆盖，同名覆盖须单独确认。账号密码与会话不保存，后台/离页关闭连接。左侧文件由当前浏览器主动选择，远端连接从工具箱电脑发起，独立于文件夹共享；详见[客户端指南](docs/USER_GUIDE.md#18-ftpftpssftp-客户端)。

## 局域网文件共享

“工具箱 → 局域网文件共享”可把电脑上的现有文件夹开放给手机和其他电脑：填写文件夹路径，选择只读或允许上传、有效期，确认后复制共享链接或扫码访问。支持子目录浏览、当前目录搜索、逐项下载；允许上传时可批量传送文件、查看进度、停止/重试和新建文件夹，同名自动另存，不覆盖原件。

文件直接保存在选定目录，不进入资源库。离开管理页后共享继续；停止、到期或工具箱退出后链接失效。默认只读，最长24小时，单文件1GiB；手机需要同网段且工具箱以Lan模式运行。操作与限制见[共享文件指南](docs/USER_GUIDE.md#17-局域网文件共享)，验收范围见[项目状态](docs/PROJECT_STATUS.md)。

## 手机扫码上传相册

从首页、“工具箱 → 手机相册上传”或资源管理页的“手机扫码上传”进入。电脑选择资源文件夹和局域网地址，生成二维码；手机扫码后可多选照片、视频，逐项查看进度、停止和重试。文件保存到电脑资源库，同名文件新建独立草稿，不覆盖已有内容。

每批最多200项、单文件1GiB、接收会话累计8GiB；二维码30分钟有效，电脑停止或离开接收页即停止接收，成功文件仍保留。需以Lan模式启动，手机与电脑处于同网段；HEIC/MOV预览取决于格式支持，原件可下载。操作与中断处理见[用户指南](docs/USER_GUIDE.md#12-手机扫码批量上传相册)。

支持实况照片：上传带内嵌视频的动态 JPEG 或 LIVP，也可在手机上传页主动开启“同名原照片 + MOV/MP4”配对。资源预览中点击“播放实况”查看动态内容，并可下载原件或动态视频；播放预览最长30秒，原件完整保留。iPhone 等手机的相册选择器可能只交出静态图，此时需另行导出原照片和动态视频。格式范围与操作见[实况照片说明](docs/USER_GUIDE.md#121-实况照片live-photo动态照片)。

## 端口查看

在首页或“工具箱 → 端口查看”读取运行本工具的Windows电脑的TCP/UDP端口、本地/远端地址、连接状态、PID和占用进程。默认展示TCP监听与UDP绑定，可按协议、精确本地端口、进程/PID/地址筛选，支持分页、复制和5秒自动或手动刷新。读取失败会标注上次快照，后台/离页暂停；仅查看，不扫描其他机器或结束进程。使用说明见[用户指南](docs/USER_GUIDE.md#11-端口查看)，实际验证范围见[项目状态](docs/PROJECT_STATUS.md)。

## 实时网速

从“工具箱 → 实时网速”或首页同名卡片进入，选择网卡，查看运行工具箱的 Windows 电脑当前下载/上传速度、对应 Mbps、最近 60 秒趋势、观察期累计流量、平均及峰值。默认优先在线物理网卡，也可选择 VPN 或虚拟网卡，单张网卡独立统计。

支持暂停/继续和清空本页记录，进入后台或离页停止轮询；全部页面停止后，服务器最多十秒释放采集。局域网客户端看到的仍是服务器电脑数据，包含该网卡的内网及互联网流量；链路速率不等于互联网带宽。操作和单位说明见 [用户指南第 10 节](docs/USER_GUIDE.md#10-实时网速)。

## 地球光照

从“工具箱 → 地球光照”或首页同名卡片进入，查看写实三维地球、当前白昼/黑夜、昼夜分界和太阳直射点。地球采用 4K 地表和夜景贴图，叠加云层、夜间城市灯光及蓝色大气边缘；金色射线表示阳光到达方向，右侧显示直射经纬度、本机时间与 UTC 时间。

太阳采用暖色光球、表面颗粒和柔和日冕。青色实线标出赤道（0°），紫色虚线标出北回归线（23.44°N）与南回归线（23.44°S），附中文标注；纬线随地球旋转，背面标注自动隐藏，简化视图也保留三条纬线。

每 30 秒自动更新，也可点击“立即刷新”。拖动地球、使用方向键或左右按钮旋转，用滚轮、双指、加减按钮或键盘 ＋/－ 缩放；点击“回到光照视角”或按 Home 恢复视角与缩放。Globe.gl / Three.js 及全部贴图随项目本地分发，无需定位、API Key 或外部地图服务；三维显示或素材加载失败时保留简化示意并可重试。云层和城市灯光是静态素材，太阳位置按本机时钟近似计算。素材作者、许可及处理说明见 [地球素材](frontend/src/assets/earth/README.md)，操作见 [用户指南](docs/USER_GUIDE.md#8-地球光照)。

## 安卓无线调试

从“工具箱 → 安卓无线调试”进入，点击“帮助”查看连接步骤与故障处理，点击“ADB 设置”弹窗搜索和选择 ADB；普通设置页也提供同一弹窗入口。界面左侧集中扫码、手动连接、无线服务搜索及设备列表，右侧为常用命令、APK 安装、手机屏幕和实时设备日志，两栏可以分别滚动。

右侧六个工具面板的标题旁各有“收起／展开”按钮。收起保留已选设备、文件及结果，进行中的任务继续执行，标题仍显示活动状态；重新进入页面恢复默认展开。

在运行工具箱的电脑安装 [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)，手机与电脑连接同一局域网，并在 Android 11 及以上的开发者选项中打开无线调试。此工具支持通过启动器显示的局域网地址访问；ADB 操作和配置路径均在运行工具箱的服务器电脑。

首次在“ADB 设置”弹窗填写已解压的 Platform-Tools 文件夹（也可填写上级 SDK 文件夹），自动搜索 `adb.exe`；找到多个版本时选择一个。关闭弹窗后点击“生成配对二维码”，在手机“无线调试 → 使用二维码配对设备”中扫码，自动配对、连接并刷新设备。二维码两分钟有效；也支持六位码配对、IPv4 地址连接和单台无线设备断开。

“常用 ADB 命令”内置六项：锁定程序、解锁程序（恢复桌面）、获取 IP、设备信息、手机内存使用和 CPU 使用。锁定与解锁从手机读取当前用户和 HOME 应用，搜索并选择程序或桌面后，核对目标再确认设置。该命令改变默认桌面，仅支持有 HOME 入口的应用；按手机主页键进入，不提供系统级禁退锁定。IP 查询全部 IPv4 接口，内存和 CPU 返回系统查询快照。详细步骤见 [用户指南](docs/USER_GUIDE.md#6-安卓无线调试)。

点击命令区“添加命令”可设置名称、分类、参数和说明，保存后在列表选择使用，支持编辑和确认删除。例如 `shell dumpsys meminfo com.example.app`，不用填写 `adb` 或设备序列号。自定义命令每次执行前展示目标与完整参数并要求确认，配置在服务器本机保存，重启后保留；具体参数范围见帮助。

“查看 APK 包名”可选择电脑上的单个 APK，点击“读取包名”，显示结果后可一键复制。无需手机、ADB 或 Android SDK，单文件最多 1 GiB；只读取清单，文件在操作结束或取消后清理。操作见[用户指南](docs/USER_GUIDE.md#612-查看-apk-包名)。

“APK 传送安装”可选择电脑上的单个 APK 和在线设备，核对文件名、大小及目标后确认传送安装。勾选“多设备安装”可多选或全选在线手机（每批最多 20 台），同一 APK 只上传一次，再逐台安装并实时显示各台结果；单台失败或超时继续下一台，可只选择失败设备重新确认安装。支持取消，已完成的安装不回滚；覆盖同包名应用并保留数据，不自动卸载或打开应用。支持最多 1 GiB 的完整 APK，AAB/APKS 不能直接安装，具体步骤及取消限制见帮助。

“手机屏幕”可选择在线设备，单次刷新或按 1、2、5 秒间隔连续读取截图；每次读取完成后再等待所选间隔。支持停止并保留最后画面、清空及放大查看。切换设备、修改配置或离开页面会停止并清空，页面进入后台会停止读取。图片只在内存中，实际刷新速度取决于设备与网络，受保护内容可能黑屏。

“设备日志”可对所选在线设备开始、停止实时 Logcat，支持最低级别、关键词、自动滚动和清空显示。日志仅保留在有界内存中，切换设备、离开页面或修改配置会结束采集；下拉菜单使用适配明暗主题的不透明底色和清晰文字。

需要查看某个 App 时，把“日志范围”切换为“指定应用”，按包名搜索并选择，查看是否运行、进程号和最后检查时间。开始采集后仅返回匹配主进程与子进程的日志，应用退出时等待，重启后定期跟随新进程；运行中表示进程存在，不代表在前台。捕获范围见用户指南。

## Unity 局域网设备日志

从“工具箱 → Unity 设备日志”进入，点击“搜索局域网”，选择 Android 手机或 iPad，即可查看设备保存的启动与热更日志。支持历史文件、等级/关键词筛选、完整堆栈、自动刷新、复制、全文及 ZIP 下载；“下载设备全部日志 ZIP”会打包设备当前保留的全部日志文件；无需 ADB、扫码或输入访问码。按固定设备编号识别，IP 改变后重新搜索。

设备需运行新版 `Assets/Test/Log` 模块，**必须重新打 APK/iOS 包，仅热更新不能加入新的发现协议**。`StartupLogManager` 默认自动开启局域网读取，应用保持前台，电脑与设备应处于可互通的 IPv4 局域网。工具页面可在同网段浏览器通过工具箱地址打开，搜索仍由服务器电脑执行，默认设备端口 17523。

搜索按网卡掩码生成范围，最多检查 1024 个地址并显示实际覆盖情况；大网段可用“搜索设置与指定 IP”补查。同 Wi-Fi 下的设备隔离、iPad 本地网络权限或防火墙仍可能阻止连接。日志只读，不自动保存到团队数据库或备份。详细操作见 [用户指南](docs/USER_GUIDE.md#7-unity-局域网设备日志)，验证与真机限制见 [项目状态](docs/PROJECT_STATUS.md)。

## Windows 源码版启动与关闭

双击启动默认允许同网段设备访问全部工具（包括 ADB、Unity 日志）。使用启动信息中的 `http://服务器IPv4:5173/`；服务器本机仍可用 localhost。仅本机使用可执行 `start.bat /local`。程序路径、设备搜索和外部应用启动均指运行工具箱的电脑；网络配置及排查见 [局域网访问](docs/USER_GUIDE.md#06-局域网访问)。

- 双击根目录 `start.bat` 启动后端和前端开发服务；两个服务都就绪后，启动 CMD 自动关闭，服务继续在后台运行。
- 同目录服务已运行时，再次点击启动只打开网页；未运行则启动，开发版部分服务退出时只补起缺少项，沿用现有 Local/Lan 模式。连续点击会复用同一组服务。
- 启动失败时窗口保留错误摘要，标准输出与错误保存在项目 `logs/` 目录，每次启动保留上一份日志。
- 双击根目录 `stop.bat` 关闭该目录下的后台服务及其子进程，保留数据文件。
- 命令行执行 `stop.bat /nopause` 可跳过结束时的按键等待；服务未运行时也可执行。

关闭脚本按项目路径识别进程。手动在终端使用相对路径启动的服务，可在对应终端按 `Ctrl+C` 关闭。发布包的启动与停止方式见 [用户指南](docs/USER_GUIDE.md)。

## 程序更新

“设置 → 更新源地址”默认使用本项目 GitHub 的最新正式 Release，支持直接填写仓库地址（含 `.git`），也可以点击“使用项目 GitHub”。检查后确认下载安装，程序会校验、备份并重启；已有自定义源与关闭状态继续保留，可使用内网更新源。更新器单独支持代理环境变量或 Windows 手动 HTTP/HTTPS 代理。操作见 [用户指南](docs/USER_GUIDE.md#07-程序更新)，发布流程见 [AUTO_UPDATE](docs/AUTO_UPDATE.md)。

## 贡献与协作

在本仓库工作前请先阅读 [AGENTS.md](AGENTS.md)；完成任务后必须更新状态文档，禁止把计划描述为已实现。

安卓调试中的 **Unity persistentDataPath 文件** 支持选择设备与应用、浏览标准外部目录、文本预览/下载、添加及确认替换；读取时版本与传送内容使用SHA256复核。使用步骤见[用户指南](docs/USER_GUIDE.md)，验证范围见[项目状态](docs/PROJECT_STATUS.md)。

**多 APK 安装**：安装面板可多选完整APK，向一台或多台手机在线安装；每台按文件顺序、最多两台并行，逐“设备 + APK”反馈结果，支持精确失败重试。步骤与限制见[用户指南](docs/USER_GUIDE.md#多-apk-安装队列)。

Windows 与网页默认品牌采用 **06「石墨字标」**，完整工具箱 TT / 独立设备工具 DD；完整工具箱设置另提供四款水墨小猫。双击根目录“创建快捷方式.cmd”可生成带图标的启动和关闭快捷方式；完整 ICO/SVG 位于 assets/icons/，操作与移动目录后的处理见[用户指南](docs/USER_GUIDE.md#应用图标与-windows-快捷方式)，实际分发状态见项目状态。

新版功能和升级方式见 [v0.6.1 发布说明](docs/releases/v0.6.1.md)，实际发布状态与验证见项目状态。

# 06 石墨字标图标

采用用户选定的 06「石墨字标」原创矢量方案（2026-11-12），深蓝灰底、浅色字形；本产品使用 TT。资产通过 SVG → PNG → ICO 生成，无外部素材或运行时依赖。

- ico/：26 个 Windows 多分辨率图标；每个包含 16、20、24、32、40、48、64、96、128、192、256 像素共 11 帧，带透明圆角。
- svg/：对应可编辑源文件；色值属于固定品牌画稿，页面业务控件仍走主题变量及 Lucide 线条图标。
- ../../frontend/public/icons/：同源网页品牌图标、ICO favicon、16/32/48/180/192/256/512 像素 PNG，无外部请求。
- 双击项目根目录“创建快捷方式.cmd”，在“快捷方式/”生成启动和关闭的 .lnk，可复制到桌面。不会启动服务、修改系统文件关联或写桌面；移动项目后重新生成。
- 安装器 EXE、程序列表图标与启动快捷方式使用 toolbox.ico；关闭入口使用 stop.ico，卸载入口使用 uninstall.ico。整套安装/启动/关闭等 ICO 可手动选用。

图标清单：android-wireless, apk-install, apk-package-info, artcraft, asset-library, backup, device, earth-sunlight, freellmapi, home, install, json-format, knowledge-base, network-speed, phone-screen, port-viewer, qrcode, ratio-lock, settings, start, stop, toolbox, uninstall, unity-files, unity-logs, yoinks。

实际验证与分发状态只记录在 docs/PROJECT_STATUS.md。
